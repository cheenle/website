## 四、逐项差距分析（NRD-535 → 现代旗舰）

| 指标 | NRD-535 | 现代旗舰水平 | 差距 | 评注 |
|---|---|---|---|---|
| 底噪 | **−135 dBm** | −141～−142（开预放） | 6–7 dB | **HF 上是伪差距**（大气噪声远高于此）；535 的 −135 在 Sherwood 全表中属优秀，比 R9000（−131）还好 4 dB |
| 灵敏度 | **0.1 µV** | 0.10–0.32 µV | **持平或更好** | 535 是全表最灵敏之一 |
| 本振相位噪声 | **117 dBc/Hz@10k** | 144–148（R8600/Perseus/7760）、154–156（FTdx-101D） | **27–39 dB** | **最大单项差距，比 R9000 的 128 还差 11 dB** |
| 阻塞@100kHz | 114 dB | 122–125（Icom 系）、>147（FTdx-101D） | 8–33 dB | 535 的跟踪预选器没有换来阻塞优势 |
| 宽间隔 DR | 92 @50k | 98–110 | 6–18 dB | 注意 535 是在**更宽的 50 kHz 间隔**下测的 |
| 窄间隔 DR | 70 @5k | 88–110 @**2k** | 18–40 dB 且间隔更窄 | 与 R9000（71@5k）同档 |
| 滤波器极限抑制 | 70 dB | 100–115 dB | 30–45 dB | 535 的滤波器组是短板（原厂件带宽偏宽），**这是可以改的**（见 REF/14 的 NDK 对照表与 Nilsson 级联方案） |
| 前端选择性等级 | B（跟踪预选器） | A/A+（FTdx-101D、IC-7760、NRD-93） | — | 跟踪预选器架构本身是先进的，等级评定低于半倍频程带通方案 |

**有趣的家族内部对比**：
- **NRD-515 的窄间隔 DR 反而最好（77 dB@2kHz，相位噪声受限）**，因为它是 0.8 倍频程前端 + 80 dB 滤波器极限；525/535 换成跟踪预选器后窄间隔掉到 72/70。
- NRD-545（DSP 后继机）窄间隔只有 68 dB——**JRC 整个模拟家族都卡在同一个相位噪声天花板上**。
- NRD-93（后来的专业机）本振噪声 133 dBc/Hz，比 535 好 16 dB，说明 JRC 后来确实改进了合成器。

## 五、第二数据源：WRTH / Radio Netherlands 实测

来源：[MWCircle 存档的 WRTH 1992 评测](https://mwcircle.org/legacy-receiver-reviews/receiver-review-nrd-535/)（详见 REF/05）

- 实测动态范围：2.6 kHz 滤波器下 **88 dB**、300 Hz 选件滤波器下 **98 dB**（厂标 106 dB 需配 300 Hz）
- 三阶截点 **+2 dBm**（30 kHz 间隔）
- 陷波器实测约 **25 dB**（厂标 −40 dB），特性偏宽
- S 表偏低：S5（约 3 µV）以下不动，S9 输入只显示约 S6
- 衰减器只有一档（20 dB）
- 显示屏自身辐射噪声比 525 严重约 3 倍
- ECSS 锁定约 2 秒、可锁到信噪比仅 3 dB 的信号，但失真从 2.7% 升到约 5%
- 预热 30 分钟后半小时漂移 <2 Hz

## 六、结论（供改造路线使用）

1. **535 的真实强项今天依然成立**：−135 dBm 底噪 + 0.1 µV 灵敏度 + 跟踪预选器 + 模拟音质，做"安静地听弱台"仍然一流。
2. **真实短板有三层**：① 相位噪声（117 dBc/Hz，改不了，代差 27–39 dB）；② 滤波器极限抑制 70 dB（**可以改**：换 NDK 等效晶体滤波器 + 级联）；③ 8–10 MHz 以上的机内数字噪声（RF 板位置，**改不掉**，Nilsson 实测确认）。
3. 与 R9000 相比：535 更安静更灵敏，但相位噪声更差、阻塞更差；两台机器的现代化路径也不同（R9000 靠 10.7 MHz IF 外挂，535 靠 70.455 MHz IF 外挂 + 滤波器升级）。
