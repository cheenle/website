# NRD-535 现代化改造路线研究报告

> 2026-09-27。第二轮深度调研（原始记录见 `REF/14`–`18`），基于第一轮基础研究（`REF/05`–`08`）。目标命题：把 JRC NRD-535（非 D 版）提升、改造、现代化到当代旗舰水平。

## 〇、先给结论

1. **535 的底噪和灵敏度今天仍是第一梯队**（−135 dBm / 0.1 µV，Sherwood 全表前列），加上跟踪预选器和模拟音质——它不需要"变快"，需要的是**修好老化、补齐滤波器、加上数字显示退路**。
2. **相位噪声是硬代差**：117 dBc/Hz@10kHz，比现代旗舰差 **27–39 dB**（甚至比 R9000 的 128 还差 11 dB）。整个 JRC 模拟家族（515/525/535/545）都卡在这条线上，无人能改。
3. **最危险的不是性能而是显示**：定制 VFD 无备件、无成功修复案例、欧洲最后一批含 CDE-705 显示单元的备件库存（CSY & SON，€350）**已售罄**。现代化方案必须把"显示死了也能用"作为一等公民——好在 RS-232 标配 + 免费 PC 软件（RXCommander、rxcontrol.org）就是现成退路。
4. **滤波器是可以真改的**（R9000 没有的条件）：Lannuier 留下的 **JRC↔NDK 对照表**让你能用廉价 NDK 等效晶体滤波器重建整条 IF 链；Sherwood 至今卖 **Collins 455 kHz 机械滤波器 + JRC 专用转接板（$129）**，明确支持 NRD-515/525/535。
5. **有一份现成的"终极配方"可复刻**：1995–97 年 Gilfer × Kiwa 的 **NRD-535GS**（$1,659.95，只卖了几十台）——3.5 kHz 定制陶瓷 + CFL-251 + AUX 可选 + 后面板旁路开关 + AGC 衰减加快 + 音频高频提升。这是被商业验证过的 DX 机改法。
6. **SDR 嫁接同样可行但取点不同**：TSP 的 IFace 官方支持 535，取 **RX 链第一混频器后的 70.455 MHz**（不是 R9000 的 10.7 MHz），SDR 需覆盖 70 MHz。

## 一、差距量化：离现代旗舰差多少

Sherwood 同实验室数据（列定义与脚注见 `REF/15`）：

| 指标 | NRD-535 | IC-R9000 | IC-R8600 | Perseus | FTdx-101D | 535 的差距 |
|---|---|---|---|---|---|---|
| 底噪 | **−135** | −131 | −132/−142ᵇ | −123/−125ᵇ | −127/−141 | **优于 R9000**，比现代开预放差 6–7 dB（HF 上无感） |
| 灵敏度 | **0.1 µV** | 0.15 | 0.40/0.12ᵇ | 0.15/0.1ᵇ | 4.5/1.6ᵇ | **全表最优级** |
| 本振相位噪声 | **117** | 128 | 144–148 | 147 | 154–155 | **−27～−39 dB** |
| 阻塞@100kHz | 114 | 129 | 125 | 125 | >147 | −8～−33 dB |
| 宽间隔 DR | 92 @50k | 93 @20k | 98–109 @20k | 99 @20k | 110 @20k | −6～−18 dB（且 535 在更宽间隔下测） |
| 窄间隔 DR | 70 @5k | 71 @5k | 88–107 @2k | 99 @2k | 110 @2k | −18～−40 dB 且间隔更窄 |
| 滤波器极限抑制 | **70** | 90 | 105–>100 | 109ᶠ | >115 | **−30～−45 dB，但这一项可以改** |

**家族内部的关键发现**：NRD-515 的窄间隔 DR 是 **77 dB@2kHz（相位噪声受限）**，比 535 的 70@5k 还好——因为 515 用 0.8 倍频程带通前端 + 80 dB 滤波器极限；525/535 改跟踪预选器后窄间隔反而下降。NRD-545（DSP 后继机）窄间隔只有 68 dB。**结论：JRC 模拟家族共享同一个相位噪声天花板，535 不是特例。**

## 二、改造路线图（按收益/风险排序）

### 第 0 阶段：健康检查与恢复（决定这台机器还能不能要）

| 项目 | 做法 | 依据 |
|---|---|---|
| **VFD 显示体检（最重要）** | 冷机/热机各看亮度；若已偏暗，试换显示单元 DC-DC 的 **4 只 35–50 V 高压电解**（成功率有限）；同时排除 CPU 参数异常（TBHD 有"显示一闪即灭"实为 CPU 问题的案例） | N9EWO；TBHD |
| 建立 PC 遥控退路 | RS-232（DB-25，4800 8N1）+ **RXCommander（HB9RXC，站点仍在线）** 或 **rxcontrol.org V1.3.6**（免费，全键盘、波段规划、自动选滤波/模式、可回读 S 表） | REF/16 |
| 电容 | Klondike Mike's 套件：**基础 70 只，有 BWC/ECSS 再加 40 只**（Rubycon/Nichicon/Panasonic，≥25 V） | REF/17 |
| AGC 过冲（官方承认的缺陷） | Nilsson 改法：**R105 短接一段使总阻 500 kΩ，R103/R104 改 100 kΩ** → FAST/SLOW 都恢复正常；或 JRC 当年 CAE-227A IF 板割线改版；或剪 CPU 板 RJ6 永久禁用 AGC OFF 档、剪 RJ5 实现 VFO↔存储切换不丢频率 | REF/14；Bob Evans 长评 |
| 记忆电池 | CR2032，额定寿命 **5 年**，所有现存机器都超期——趁未死更换 | REF/06 |
| 主振荡器校准 | Nilsson：**主振荡器必须精确校到零**，才能发挥其极高稳定度（另：时钟走偏 → CDE-705 的 TP1 接频率计调 CV1） | REF/14；维修手册 |
| 旋钮阻尼 | 磁编码器本身可靠，问题是旋钮太轻/惯性大 → 刻度盘与轴间垫毡垫圈 | Bob Evans；JA4FUQ |
| 按键 | 前面板小开关接触不良 → 酒精清洗（通用件可购） | JA4FUQ（本地存档） |

### 第 1 阶段：滤波器升级（535 相对 R9000 的独特优势项）

**目标**：把 70 dB 的滤波器极限抑制和偏宽的原厂带宽拉到现代水平。

1. **买 NDK 等效件，不要追 JRC 原厂编号**（Lannuier 对照表）：CFL-231=YF455FM(240 Hz)、CFL-232=YF455DQ(500 Hz)、CFL-233=YF455DE(1.0 kHz)、CFL-218A=YF455EBF(1.8 kHz)、CFL-251=YF455EB(2.4 kHz)。
2. **Sherwood 的 Collins 455 kHz 机械滤波器 + JRC 转接板**：$129/套，明确适配 NRD-515/525/535；**现存带宽只有 6 kHz 与 5 kHz**（NOS 库存将尽）；另有大号 455 kHz 晶体滤波器 **2.4 / 2.1 / 400 Hz**，同样 $129 含板。这是把"极限抑制"直接拉高一个档次的现成商品路径。
3. **复刻 NRD-535GS 配方**（Gilfer×Kiwa，商业验证过）：INTER 位换 **3.5 kHz 陶瓷**（替原厂 2.2 kHz）、NARR 位装 **CFL-251 2.4 kHz**、AUX 位按需装 300/500/1k/1.8 kHz、**后面板加拨动开关旁路 AUX 级**（用机器本身 12 kHz 通路听宽音频节目）、AGC 衰减加快、音频高频截止提升。
4. **Nilsson 级联思路**（进阶）：仿他在 525 上的做法用 Eskab 板做多级级联；注意 **滤波器两侧必须装 20 kΩ（R25/R26/R16/R17/R40/R41）否则阻抗失配、曲线严重纹波**；Eskab AVC 板上 **1 µF 钽电容必须换 10000 pF 瓷片**，否则恢复时间过慢。
5. **早期批次必做**：若你的 535 宽滤波器还是 **CLF-D6（约 8 kHz）**，换成 **CLF-D6S（5.7 kHz@−6dB，8.7 kHz@−60dB）**——这是 JRC 自己承认的倒退并已免费更换过。
6. **BWC 现实预期**：Fenu 与 Nilsson 都认为 BWC"不够陡峭、印象不深"，且 Nilsson 报告 **855 kHz 音调**在转动旋钮时可闻。若你的机器序列号 <56005/BR56005，BWC 只能控制 wide 位；升级需 CFL-243W 板 + EPROM "D"（当年 JRC 提供套件，现只能找拆机件）。**鉴别法**：看 BWC 在 AM 模式下对 wide 滤波器是否起作用。

### 第 2 阶段：ECSS 与数字能力

- **补装 ECSS 板 CMF-78**：日本市场单板约 **4,801 日元**（BWC 板则要 1.4–3.5 万日元），是性价比最高的选件补齐。注意 Fenu 的警告：**ECSS 漂移失锁只发生在校准不良的机器上** → 装完务必做整机校准。
- **DRM/窄带数字模式改装**（drmrx.org V1.02 完整文档）：455 kHz 经 LC 混频器降到 **12 kHz**，后面板加 3.5 mm 座 → 声卡 → DReaM。取点在 **CFH-36A IF 滤波板**：供电 P30 pin1（10.8 V）、455 kHz 在 P30 pin22、地 pin21；或用通用方法在 **C19/L3 之后、FL3–FL6 之前**取。2003 年实测 SNR 高达 30 dB。（今天 DRM30 只剩印度 AIR 等极少数发射台，工程价值大于实用价值，但同一 12 kHz 通路可用于其他声卡解调模式。）
- **RTTY**：选件 CMH-530（45/50 baud Baudot，85/200/425 Hz 三种频移）。
- **外置音频 DSP**（可选）：bhi NES10-2 MK4（最多 40 dB 降噪）或 Timewave DSP-599zx（降噪 20 dB、自动陷波 50 dB、延迟 5–58 ms）；配合 **NVA-319** 原厂匹配音箱。注意 Kiwa 的音频改比外挂 DSP 更治本（原厂声音闷是频响问题）。

### 第 3 阶段：SDR 嫁接（全景显示 + 数字解调）

TSP Electronics 的 **IFace 缓冲板官方支持 NRD-535**，文档给出 RF TUNE 板与 MOTHERBOARD 的原理图取点、PCB 实物取点与供电点：

```
天线 → 跟踪预选器 → RF 放大 → 第一混频
                              │
                              ├─（原厂通路）70.455 MHz → 455 kHz → 97 kHz → 模拟解调 → 喇叭
                              │
                              └─ tap：第一混频器输出（宽带信号围绕 70.455 MHz）
                                  → IFace 高阻缓冲（50 Ω 输出）
                                  → SDR（需覆盖 70 MHz：RTL-SDR 调谐器模式 / SDRplay / Airspy）
                                  → PC：HDSDR / SDR Console（若频谱反转则勾 Swap I/Q）
                                      ├─ 全波段瀑布图（535 原生没有任何频谱显示）
                                      ├─ 数字降噪 / 陷波（作用在 I/Q，比音频 DSP 信息更全）
                                      └─ 录音、解码
RS-232（DB-25，标配）→ RXCommander / rxcontrol.org / OmniRig：PC 与机器双向联动
```

**与 R9000 方案的三点差异**：① 取点在 **70.455 MHz**（不是 10.7 MHz），SDR 必须能收 70 MHz；② 535 **没有原厂 IF 输出口**，必须机内取点（R9000 可先用背板 IF OUT 试水）；③ 535 的 CAT 是**标配 RS-232**（比 R9000 的 CI-V 更方便，连 S 表都能回读）。频谱是否反转文档未说明，需实测确认。

**注意**：取点在第一混频后、一中频滤波之前，频谱最宽但未经滤波保护，强信号环境下 SDR 前端可能过载（用 SDR 自身衰减档缓解）。另外 Patrick Canler 实测发现 **535 的显示屏会干扰旁边的 RadioJet SDR** → 布线时让 SDR 与天线远离显示单元。

### 第 4 阶段：前沿空白（无人做成，价值最高）

- **CDE-705 显示单元的现代替代**：全球**无任何公开案例**（LED/OLED 段码屏替代、小型 LCD + 自写驱动走 RS-232 回显频率、NRD-545 屏幕移植都无人做过）。相比之下 IC-R9000 的 CRT→LCD 已有成熟商品方案——**这是 535 玩家能做出的最有价值的贡献**。已知约束：显示单元内含 PG1 编码器与 IC7（调谐功能也在这块板上！），所以替代方案必须保留编码器接口，否则调谐失灵；维修手册有 CDE-705 的时钟校准（TP1/CV1）与 RV1/RV2（PBS/BWC）信息。
- **相位噪声改进**：无案例，且合成器与 DDS/PLL/CPU 深度耦合，等同重造机器——不建议。
- **8–10 MHz 以上数字噪声**：RF 板离机箱太近，Nilsson 用 4 台机器实测"所有办法都试过，消不掉"——**设计性缺陷，接受它**（实用对策：该频段以上主要靠 SSB/ECSS + 窄滤波 + 外接天线远离机箱）。

## 三、预算与期望管理

| 路线 | 成本 | 得到什么 |
|---|---|---|
| 第 0 阶段（恢复健康） | $100–200（电容套件 + 电池 + 工时） | 一台可靠、AGC 正常、显示尚可的 535 |
| + 滤波器升级 | +$129–400（Sherwood Collins 套件 / NDK 等效件 / 复刻 GS 配方） | 极限抑制从 70 dB 大幅提升，选择性达到现代水平 |
| + ECSS 板 | +约 ¥4,800（≈$32） | 同步检波，AM 广播 DX 的招牌功能 |
| + SDR 嫁接 | +$60–150（IFace + RTL-SDR/SDRplay） | 全景瀑布、数字降噪、录音——535 原生完全没有 |
| + 显示替代（自研） | 不可估（无先例） | 解决唯一的单点致命故障 |

**能达到的**：听感与易用性**超越**多数现代 SDR（Patrick Canler 2016 年把 535 排在 RadioJet 1102S 之前，理由是"易用性 + 从 QRM 中挖出可用信号的能力"，并批评数字滤波"声音发干"）；灵敏度与底噪本就是第一梯队；选择性可通过滤波器升级补齐；功能上通过 SDR 嫁接补齐频谱显示与数字降噪。

**达不到的**：近端动态范围与本振相位噪声（差 27–40 dB，物理与架构决定）；8–10 MHz 以上的机内数字噪声；VFD 的原厂修复。

**正确定位**：535 做"听感优先"的主力 DX/广播接收机 + PC 软件做频率管理与日志 + SDR 提供瀑布；把 contest 式密集信号、需要近端动态的场景交给现代 SDR。与 R9000 的分工依旧成立：**535 管 HF 的耳朵，R9000 管 VHF/UHF 以上的眼睛**。
