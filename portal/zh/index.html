项目

探索项目套件

六个开源项目 —— 通用 HF 电台、SDR 平台、数字模式 DSP 服务器、天线自动化、多电台 USB 原生控制，外加一层云端接入。

MRRC

通用 Web 远程收发信机控制系统。通过 Hamlib/rigctld 支持任何 HF 电台。Opus 优化音频、WDSP 降噪、AI 语音助手（Whisper + Qwen TTS）、CW/FT8 数字模式、录音室级 TX 音频处理、三层 PTT 安全系统。

  • V5.6.5 · 280+ 提交 · GPLv3
  • 通过 Hamlib/rigctld 支持任意 HF 电台
  • WDSP NR · PTT 安全 · AI 语音 · FT8
网站 源码 演示

MRRC Modern

八重洲 FT-710 与 Icom IC-7300/IC-7300MK2 的可插拔后端 USB 原生远程控制。FT4222 SPI 或 CI-V 频谱、双向 Opus 48kHz 音频、4 条 WebSocket 通道完整 CAT/CI-V 控制——同一套代码，支持多台电台。

  • v1.12.1 · 682 项测试 · GPLv3
  • FT-710 + IC-7300 + IC-7300MK2 后端
  • 直连 USB · 无需 Hamlib · PWA + 移动应用
网站 源码

MRRC Cloud Hub

给内网、运营商大内网或 IPv6 常变的 MRRC Modern 实例做接入层：实例主动出站，因此不需要公网地址、端口映射或 UPnP。呼号即入口，同一呼号只对应一个入口。电台控制、音频、频谱与 PTT 安全仍归 MRRC Modern，接入层不复写它们。

  • 设计已评审 · MVP 未实现
  • 阶段 1 已跑通：出站隧道 · 通配入口 · 真证书
  • PTT 释放留在实例本地
网站 源码

SunMRRC

SunSDR2 DX 专用 FastAPI 后端服务器。服务器端 IQ 解调、实时 512-bin FFT 频谱瀑布、双编解码 Opus/PCM 音频、基于 Hilbert 变换的 TX SSB 语音调制、波段功率控制、5 路 WebSocket 端点为 Web 和原生客户端提供服务。

  • V1.0 · 65+ 提交 · GPLv3
  • 5× WebSocket · IQ DSP · Opus/PCM
  • 逆向工程 SDR 协议
网站 源码 演示

EFHW Projects

端馈半波天线研究与自动化。ESP32-S3 连续伺服调谐适配器，偏压器同轴供电，WiFi WebSocket 控制，100W PEP，40m–10m 全覆盖。Fuchs LC 耦合器采用 T200-6 磁环和空气可变电容——与 MRRC 生态系统深度集成。

  • V3.0 · ESP32-S3 · GPL-3.0 / CERN-OHL-S 2.0
  • 室外自动调谐器 · 偏压器供电 · IP66
  • Fuchs LC 耦合器 · 伺服驱动 · NVS 学习
网站 源码 研究

MRRC-FT8

基于 WSJT-X 3.0.2 Improved DSP 核心的 headless FT8/FT4 服务器，运行在受监督的独立 Worker 之后。UTC 时隙纪律、按操作者选择自动完成一场标准 QSO 的 sequencer、3 kHz 瀑布图、带 ADIF 导出的持久化 SQLite 日志，以及横屏移动驾驶舱——已在 FT-710 电台上线。

  • v0.1.0 · 937 项测试（collected）· GPLv3
  • WSJT-X Improved ft8var OpenMP 解码
  • 单一控制租约 · 通用 STOP TX

RIG · 专栏

传奇电台深度剖析

一次只讲一台机器：它当年是怎么设计的、今天在实验室里测出来是什么水平、会老化成什么样以及怎么修，还有一份对"能改什么、改不了什么"诚实交代的现代化路线。进入专栏 →

第 1 期 · ICOM IC-R9000

1989 年旗舰的解剖：0.1–2000 MHz、四次变频、内置 CRT 频谱仪——以及 Sherwood 实验室数据与 2026 年旗舰的逐项对比。每一种有记录的老化故障及其修法，然后是分阶段路线：散热、换电容、换液晶、把 SDR 嫁接到 10.7 MHz 中频上。

  • 1989–1998 · 598,000 日元 / 4,795 美元
  • 底噪 −131 dBm · 邻近动态范围 71 dB
  • CRT → LCD · 中频引出 → SDR 瀑布图
阅读全文 English

第 2 期 · JRC NRD-535

日本无线（JRC）最后的全模拟旗舰：跟踪预选器、1 Hz DDS、WRTH 1991 年度最佳——以及一块没有修法、也没有备件的荧光显示屏。来自 JRC 前美国销售经理的设计内幕、JRC↔NDK 滤波器对照表、Gilfer × Kiwa 的 NRD-535GS 配方，以及在 70.455 MHz 一中频上的 SDR 嫁接。

  • 1991–1997 · 1,200 美元（535D：1,690 美元）
  • 底噪 −135 dBm · 灵敏度 0.1 µV
  • 滤波器升级 · ECSS · RS-232 退路
阅读全文 English

配套专题 · Yaesu FT-710

现代对照组：一台没有顶滤波器的直接采样 SDR，2 kHz 邻近动态范围实测 107 dB——Sherwood 榜单第 3，也是 1,100 美元以下唯一破 100 dB 的机器。纠正两个流传甚广的错误说法（屏幕是 4.3 英寸，频谱跨度 1 kHz–1 MHz）、两家实验室的完整数据、固件史到 V01-12、全部有据可查的坑点，以及七条远程控制路径的横评——包括我们自己逆向出来的、官方从未文档化的 FT4222 频谱通道。

  • 2022 年至今 · HF/6m 100 W · 4.5 kg
  • IPO 底噪 −127 dBm · 本振相噪 150 dBc/Hz
  • 阻塞 129 dB——这是架构上的取舍
