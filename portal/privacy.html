Privacy Policy

Last updated: August 12, 2026

Summary

This website (www.vlsc.net) is a static informational site. It has no user accounts, no login, no comment forms, and no newsletter. In short: we collect almost nothing about you, and everything we do collect is standard web-server operation.

What this site does not collect

  • No personal data you give us — there are no forms, no registration, no payment processing, and no email signup on this site.
  • No first-party analytics — we do not run Google Analytics, Matomo, or any visitor-tracking script of our own.
  • No first-party cookies — this website itself does not set cookies.

Server logs

The web server (nginx) records standard access logs: the request IP address, the page requested, the HTTP user-agent string, and timestamps. This is normal operation for any web server and is used for security (detecting abuse), diagnostics, and aggregate traffic statistics. Logs are not sold or shared with third parties, and they contain no personal information beyond what a browser sends to any website.

Third-party advertising — Google AdSense

This site may display advertisements served by Google AdSense. Google, as a third-party vendor, uses cookies and similar storage technologies to serve ads based on your prior visits to this and other websites.

  • DoubleClick DART cookie — Google uses the DoubleClick cookie (and similar identifiers) to serve relevant ads and to measure ad performance.
  • Personalized advertising — Google may use collected data to serve personalized ads. You can opt out of personalized advertising in Google's Ads Settings.
  • How Google uses data — you can read how Google uses data when you use sites that use AdSense at policies.google.com/technologies/partner-sites.
  • Google's Privacy Policy — policies.google.com/privacy.
Because Google AdSense is a third-party service, the cookies and other storage it uses are governed by Google's policies, not ours. Blocking or deleting third-party cookies (or enabling "Do Not Track") may reduce the number of ads you see but will not affect the content of this site.

Other third-party services

This site loads the following third-party resources, which may see your IP address as part of normal web requests:

  • Google Fonts (fonts.googleapis.com / fonts.gstatic.com) — for the Inter and JetBrains Mono typefaces.
  • Font Awesome (cdnjs.cloudflare.com) — for icons.
  • GitHub (github.com) — links to project repositories; we do not load GitHub scripts on our pages.

Live demos

Some pages link to live radio demos hosted on radio.vlsc.net. If you open one, you will be using the demo server directly; it may record standard connection logs like any web service. Closing the demo does not leave anything behind on this site.

Your choices & contact

If you have questions about this policy, or if you are in a jurisdiction (such as the EU/EEA or California) that grants you specific privacy rights and you would like to exercise them, contact us:

  • Email: contact@vlsc.net
  • GitHub: github.com/cheenle

Changes to this policy

If this policy changes, the "Last updated" date at the top of this page will be revised. Material changes will be called out on the project's GitHub repositories.
