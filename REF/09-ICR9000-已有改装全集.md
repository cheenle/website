## 1. CRT → LCD 换装（最成熟、方案最多）

**改什么**：用 5 寸 LCD + 驱动板替换东芝产琥珀色 CRT 监视器组件。R9000 的 CRT 本质是一台 NTSC 复合视频（CVBS，1 Vp-p）监视器，这是换装容易的根因。

**怎么改 / 方案**：
- **官方路径**：Icom 1999 年推出的 [IC-R9000L 本身就是 CRT→5 寸 TFT LCD（320×234）的官方改款](https://www.universal-radio.com/catalog/widerxvr/4151.html)；R9000L 的 LCD 组件可用于换装，但 [日本玩家指出 R9000L 的维修受理也已终止，原厂件基本不可获得](http://www.seidensha-ltd.co.jp/~seiden/ic-r9000.html)。
- **通用 NTSC 监视器模块**（mods.dk 文章方案）：阿里巴巴 VS Displays 店的成品 LCD 套件（见上）。
- **VGA 控制板 + 5 寸 LCD 散件**（详细 DIY 记录，[seidensha-ltd.co.jp](http://www.seidensha-ltd.co.jp/~seiden/ic-r9000.html)）：控制板支持模拟 RGB 和 NTSC 两路输入；实测整套 LCD 仅耗电约 160 mA（标称 12 V/2 A 系误标），直接从 CRT 供电的 6P 连接器取电，视频走原 RCA 针插；拆下的 CRT 组件重 1740 g；安装用原 CRT 缓冲海绵胶粘固定，不打孔、可完全还原。开机瞬间右上角有绿色"AV"输入提示，数秒后消失。
- **成品替换模块**：eBay 有专门的 ["ICOM IC-781 IC-R9000 LCD Module replacement part"（多色排线版）](https://www.ebay.com/itm/389569378512)。
- 视频实例：[YouTube《Icom IC R9000 Update》](https://www.youtube.com/watch?v=DdWQxR16BOQ)——CRT 改 LCD"升级成 R9000L"，同时加装内部散热风扇、S 表灯泡换 LED。

**效果**：消除烧屏/老化风险；省约 1 A 电流（见第 5 节荷兰 RCD 切断 CRT 供电的实测数字）；减重约 1.7 kg；整机发热显著下降。

**不修 CRT 时的维修方案**（[bunkerofdoom.com KD5OEI](http://bunkerofdoom.com/r9000/Page.html)）：垂直线性不良/顶部折叠 → 换 CRT 板上的 **C407、C410**（同容量、105 °C、低 ESR、高耐压），并重焊 T201/L201/L202/D205/D206/Q202/Q203/IC401/L203/Q105/D401 等通孔件裂纹焊点；几何/亮度/聚焦用机内 H-PHASE、V-HEIGHT、V-LIN、SUB-BRI、CONT 等电位器重新调校。视频信号本身失真（同步丢失）→ 换视频发生器 CRTC 板上的 **C11**（封闭结构内长期高温干涸，[同站另一篇](https://bunkerofdoom.com/r9000/index.html)，作者直言"这机器内部很热，Icom 应该加风扇，你应该加风扇"）。

## 2. 散热改装（Cooling Kit 与 DIY 风扇）

- **Sherwood Cooling Kit**：[更换带风扇的后面板组件，$149，代装 $65](http://www.sherweng.com/r9000ck.html)（页面注明安装内容）。YO9FZS 在其维护文中明确建议"为避免 REG 单元日后过热，可安装 Sherwood 风扇套件或自制方案"（[PDF](http://www.radiomanual.info/schemi/ICOM_HF/IC-781_technical_and_maintenance_issues.pdf)）。
- **DIY 120 mm 风扇**（[RadioReference 帖](http://forums.radioreference.com/threads/icom-ic-r9000-rear-sherwood-fan.479415/)）：三速 Antec 机箱风扇用扎带固定在后面板散热孔正中（对准主散热器），最低速档、从 R9000 背板 12 V 圆孔取电；实测"关机风扇停转后 30 分钟内有暖风排出，之后降到略高于室温"，低速档多年使用几乎无声。热是这些机器电容老化的元凶，作者建议必加。
- 过热受害重点部位（[ICOM 官方老 FAQ](https://www.qsl.net/icom/oldicomfaq/ic-r9000.html)）：稳压/DC-DC 变换器（屏蔽罩内）电解电容老化 → -12 V/-7 V 轨异常 → 静噪错乱、S 表不归零，对策是**更换 DC-DC 变换器段全部电解电容**；YO9FZS 文中对应 IC-781 REG 板的烧毁区（R32/Q7/R26 附近烧板烧线）给出了完整修复件清单（Q7 可用 70 W/8 A 的 TIP132 达林顿替代，电解电容一律换 105 °C 品，并在 280 V 线加 3.15 A 保险丝）。

## 3. 滤波器升级

**原厂滤波器阵容**（[seidensha 拆机照片标注](http://www.seidensha-ltd.co.jp/~seiden/ic-r9000.html)）：455 kHz 晶体滤波器 FL-44A（±1.2 kHz）、FL-52A（±250 Hz）；455 kHz 陶瓷滤波器 CFW455B（±15 kHz）、CFW455E（±7.5 kHz）、CFW455HT（±3 kHz）、CFJ455K5（±1.2 kHz）；另有 FL-117（±3 kHz）。即 AM 模式标准可选带宽只有 15/9/3 kHz。

- **Sherwood"滤波选择升级 + 逻辑板"**（[sherweng.com/radios.html 的 R9000 专节](https://web.archive.org/web/2018/http://www.sherweng.com/radios.html)）：Sherwood 认为 R9000"近乎完美，只有两个短板——AM 选择性选择少、无同步检波"。该改装**启用原本只在 SSB 用的 6 kHz 滤波器并加装切换逻辑板**，AM 从 15/9/3 kHz 变为 15/9/6/3 kHz 四档。安装价 $295。
- **Collins 机械滤波器**：Sherwood 的 [Collins 455 kHz 机械滤波器转接板页面](http://www.sherweng.com/collins.htm)列出的适配对象是 NRD-515/525/535 和 Racal 6790GM，**没有 R9000 的现成转接板**；裸滤波器 $119 可供实验者自行适配。未发现有人公开发表过 R9000 换 Collins 机械滤波器的完整案例——这一点应视为方案空白（R9000 的窄带滤波在 455 kHz 级用晶体/陶瓷滤波器，理论上可自行适配，但无文档）。
- 荷兰 RCD 的专业改装也包含"改变某些滤波器特性"（配合 10.7 MHz IF 路径改造），但 [Crypto Museum 页面](https://www.cryptomuseum.com/df/icom/icr9000/mod.htm) 标注 under construction，未给出滤波器细节。

## 4. 同步检波 + 455 kHz 下变频器（Sherwood 招牌改装）

- **Sherwood 455 kHz 下变频 + 缓冲滤波板**：把 R9000 的末级 10.7 MHz IF 下变频为缓冲的 455 kHz 输出，驱动 SE-3 同步 AM 检波器，安装价 $295；SE-3 Mk IV 本体 $695（[来源同上](https://web.archive.org/web/2018/http://www.sherweng.com/radios.html)）。
- **效果**（[eHam SE-3 评测页](https://www.eham.net/reviews/detail/4536)，含 R9000 用户 KD5VC 的实证）："Rob 在 R9000 里用一套缓冲/变频/滤波板把末级 IF（10.7 MHz）变换给 SE-3 使用"；SE-3 输入高阻、IF 取样点在 AGC 之后，"NE602 的 80+ dB 动态范围不影响接收机本身能力"；SE-3 自带带高音切除/低音提升的音频放大器。多位评测者（Ten-Tec RX-340、Racal RA3702、Collins R-391 等机型用户）一致认为其选择性衰落失真消除效果显著优于各机内置同步检波。
- [SE-3 技术页](http://www.sherweng.com/indepth.html)：系统带宽由接收机 IF 滤波器决定（6 kHz 滤波 → 全偏移时 6 kHz 响应），SE-3 音频响应 30 Hz–15 kHz（-3 dB）。

## 5. 10.7 MHz IF 输出的利用与改造

- **原厂 IF 输出的缺陷**（[Crypto Museum 改装页](https://www.cryptomuseum.com/df/icom/icr9000/mod.htm)，荷兰无线电监测局 RCD/PAN-2000 截获系统改装档案）：原厂 IF 输出用 CINCH/RCA 插座且位置不佳、会拾取杂散和噪声。RCD 的做法：切断原灰色同轴线，换**特氟龙同轴线**直接焊到 IF 单元原插座焊点，后面板**新装 BNC 座**；同时新增**鉴频/中心表（CM OUTPUT）BNC 输出**——信号取调解板的 IC14 第 1 脚（R221 上端），经 10 kΩ 串联电阻引出，屏蔽接 R224 地端；另有改 AGC 电路、更换 10.7 MHz IF 路径（细节未完）。
- **SDR 频谱仪（IFace 缓冲接口）**（[TSP Electronics](https://www.tspelettronica.com/en/2020/06/29/panadapter-sdr-per-ic-r9000/)）：在 IF UNIT 第二混频级之后取 **10.7 MHz IF（全波段同一 IF）**，经 IFace 缓冲板馈给 SDR 做全景显示；页面给出了 IF UNIT 原理图上的精确取样点和取电点；接收机无需 PTT 信号。
- **接数字解码器**（[RadioReference 数字模式帖](http://forums.radioreference.com/threads/ic-r9000-digital-modes.475682/)，2024 年实测）：AOR AR-DV1 锁定 10.7 MHz 接 R9000 IF 输出即可自动解 DMR/D-STAR/C4FM/Tetra 等；**注意 R9000 的 IF 输出频谱是反的**，需在 DV1 菜单把 IF DIR 设为 REV（F→9→下箭头→IF DIR→REV→ENT）；RCA 旧视频线在 10.7 MHz 损耗大导致电平偏弱，换 BNC-BNC 射频线后"set and forget"正常工作。提示：个别 Icom 的 IF 口带直流，接入前需确认/加隔直。

## 6. 供电与功耗类改装（荷兰 RCD 档案）

[同一 Crypto Museum 页面](https://www.cryptomuseum.com/df/icom/icr9000/mod.htm)：
- **拆除内置电源**：移动使用时拆掉笨重的工频变压器电源减重；直流供电时须拔掉背板跳线插头，**最低工作电压 13.5 V（PAN-2000 供 15 V）**，DC 插头可用旧硬盘电源插头改制。
- **切断 CRT 供电**：面板 DISPLAY 键只断视频不断电；剪断 CRT 壳后连接器的棕色线、引到改装的 5 针 DIN DATA 座（退役机主多用短接插头恢复）。作者改良为在顶部选件舱盖下的选件板上加开关。实测**整机省电 1 A**。
- **禁用定时器开关**（误触会导致遥控上电失效）；REMOTE 口从 3.5 mm 改为 BNC（更牢靠）。

## 7. CI-V / 计算机控制

- 原厂配件 [CT-17 CI-V 电平转换器](https://www.rigpix.com/icom/icr9000.htm)（RS-232C↔CI-V）；[CT-16 卫星接口、UT-36 语音合成器、SP-20 滤波外置音箱](https://donegal-holdings.com/ic-r9000_specifications.htm)同属官方选件。
- RCD 把 REMOTE 口改成 BNC 用于 PAN-2000 遥控（见上）。
- 现代方案：FTDI USB CI-V 线（[Valley Enterprises CT-17 USB 线](https://www.valley-ent.com/store/icom-ct-17-usb-ftdi-chipset-ci-v-cat-control-programming-cable-3-feet.html)、[bluemax49ers R9000 专用串口线](https://bluemax49ers.com/product-explorer/icom-ic-r9000-serial-ci-v-cat-programming-cable-ct-17-dos/)）；[ICOM-ICR-9000 groups.io 讨论](https://groups.io/g/ICOM-ICR-9000/topic/software_for_scanning/69296331)确认 CI-V 命令集文档齐全、电台地址可在 R9000 屏幕上改，第三方扫描控制软件可用；免费开源的 [UDel Mills ICOM CI-V 控制程序](https://www.eecis.udel.edu/~mills/icom/) 亦支持 CI-V 接收机。

## 8. 音频输出改进

未找到专门的"音频电路改装"公开方案；已有做法集中在三处：
- SE-3 同步检波器自带带高切/低音提升的音频放大器，兼任音频增强（eHam 评测原话 "not only as a synchronous detector, but as an audio enhancer"）。
- 原厂 [SP-20 外置音箱（内置音频滤波器）](https://www.rigpix.com/icom/icr9000.htm)。
- 日本玩家确认机内喇叭本身尺寸较大（[seidensha](http://www.seidensha-ltd.co.jp/~seiden/ic-r9000.html)），整机音频规格 2.5 W/10% 失真/8 Ω（RigPix）。

## 9. 频率基准（TCXO/外参考）——调研结论：无公开成品方案

- 原厂指标（[RigPix](https://www.rigpix.com/icom/icr9000.htm)）：HF ±25 Hz、30 MHz 以上 ±0.25 ppm（0–50 °C），基准振荡器在 **PLL B 单元**上（[ICOM 官方 FAQ](https://www.qsl.net/icom/oldicomfaq/ic-r9000.html) 排障时先查"reference oscillator output on PLL B unit"）。
- Icom 的 CR-293 高稳晶振（±0.5 ppm）是给 IC-R8500/IC-820H/IC-910 等机型的选件（[Icom 官网](https://www.icomjapan.com/lineup/options/CR-293/)，中心频率 30.200 MHz），**不适用于 R9000**；R9000 没有官方高稳选件。
- 检索未发现任何已发表的"R9000 外接 10 MHz GPSDO 基准输入"改装记录。这属于方案空白：理论上可仿照 RCD 改后面板 BNC 的思路，把 PLL B 基准换成可注入式，但无现成文档可引。

## 10. 其他维修性"恢复性能"条目（ICOM 官方 FAQ 精选）

[来源](https://www.qsl.net/icom/oldicomfaq/ic-r9000.html)：CPU 地址故障 → SW-D 单元 J7 插 W1 跳线后复位；CRT 间歇 → 重焊 CRT 板所有焊点；热机 FM 啸叫 → 换 PLL B 的 IC15（768 Hz VCO 温敏）；500–999/1000–1499 MHz 接收差 → 查 PLL B 的 268 MHz VCO；V/UHF 灵敏度低 → 背板 N 座芯被 PL-259 撑开；频谱中心偏移 → 按维修手册 5-14 页做 Center Freq/Horizontal Scale/AFC Center 调整。另附实用的 S 表/频谱仪对照表（14.1 MHz、前置放大关、25 kHz 分辨率：1 µV 无偏转/频谱第 1 格，50 µV=S9，1 mV 满格）。

## 基准数据存档

[Sherwood 接收机实测表](http://www.sherweng.com/table.html) 中的 R-9000 行：底噪 -131 dBm、AGC 阈值 0.8 µV、100 kHz 阻塞 129 dB、灵敏度 0.15 µV、本振噪声 128 dBc/Hz@10 kHz、滤波器极限抑制 90 dB、宽间隔 DR 93 dB@20 kHz、窄间隔 DR 71 dB@5 kHz（均为 SSB 滤波器下测得）。同表还收录了 R9500（宽间隔 110 dB 但滤波器极限仅 80 dB）可作对照。
