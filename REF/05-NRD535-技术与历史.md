# JRC NRD-535 技术与历史调研报告

## 一、机型定位与生产年代

- **系列定位**：NRD-535/535D 是 JRC 半专业接收机家族的第四代产品，谱系为 NRD-505 → NRD-515 → NRD-525 → NRD-535；全模块化插板设计，表面贴装元件，关键射频电路优先使用分立元件而非集成电路（[ZCM Services](https://www.zcm.com.au/nrd535.htm)、[Bob Evans 评测 PDF](http://bee.mif.pg.gda.pl/ciasteczkowypotwor/%23ham_radio/Other/JRC_NRD-535D_review.pdf)）。
- **上市时间**：1991 年 4 月进入北美市场（Bob Evans 评测）；获 **1991 年度 WRTH（世界广播电视手册）"最佳通信接收机"行业奖**（[MWCircle / WRTH 1992 评测](https://mwcircle.org/legacy-receiver-reviews/receiver-review-nrd-535/)、[ZCM](https://www.zcm.com.au/nrd535.htm)）。
- **生产年份**：RigPix 数据库记载 **NRD-535：1991–1997**；**NRD-535D：1991–1998**（[RigPix NRD-535](https://www.rigpix.com/jrc/jrc_nrd535.htm)、[RigPix NRD-535D](https://www.rigpix.com/jrc/jrc_nrd535d.htm)）。MWCircle 记为 1991 推出 / 1998 停产（535D 生产至 1998 年夏）。后继机型为采用 DSP 的 NRD-545（[MWCircle](https://mwcircle.org/legacy-receiver-reviews/receiver-review-nrd-535/)）。
- **价格（当年）**：NRD-535 标准版约 US$1200 / £1750 / A$3075；NRD-535D 约 US$1690 / £1995 / A$3990（MWCircle）。Bob Evans 评测时 535D 街价 $1699（后涨至约 $1809）。eHam 标 MSRP $1600（[eHam](https://www.eham.net/reviews/view-product?id=6090)）。

## 二、完整技术规格（标准版 NRD-535）

来源：[RigPix NRD-535](https://www.rigpix.com/jrc/jrc_nrd535.htm)、[Universal Radio 规格页](https://www.universal-radio.com/catalog/commrxvr/1535spec.html)、[Universal Radio 目录页](https://www.universal-radio.com/catalog/commrxvr/1535.html)

- **频率范围**：官方标称 90 kHz–30 MHz 连续覆盖（实际可调谐更低，约 30 kHz 以下只能听到本机合成器噪声；MWCircle 在荷兰实测可收 77.5 kHz 的 Mainflingen 授时台）。
- **模式**：AM / USB / LSB / CW / RTTY / FAX / 窄带 FM。
- **变频架构**：三次变频超外差——**第一中频 70.455 MHz**（Universal 规格页给出精确值 70.45399 MHz）、**第二中频 455 kHz**、**第三中频 97 kHz**（FM 例外，不经过第三中频）。
- **频率合成**：DDS + PLL 混合合成器，**1 Hz 调谐步进**（1/10/100 Hz、1 kHz 可选），显示分辨率 10 Hz；真空荧光管大屏幕显示（Universal）。
- **频率稳定度**：±2.5 ppm（50 分钟预热后；RigPix）/ ±10 ppm（5–60 分钟）、±2 ppm（1 小时后；Universal）；选件 **CGD-135 TCXO** 可达 ±0.5 ppm（-20~+50°C）。MWCircle 实测预热 30 分钟后半小时漂移不足 2 Hz。
- **灵敏度（10 dB S/N，RigPix）**：SSB/CW 1.6–30 MHz：**0.32 µV**；AM 1.6–30 MHz：2 µV；FM（12 dB SINAD）：0.5 µV。（Universal 规格页保守标 0.5 µV SSB/CW。）
- **镜像/中频抑制**：>70 dB；**动态范围**：厂方标称 106 dB（@300 Hz 带宽），但 WRTH/Radio Netherlands 实测 2.6 kHz 滤波器下仅 88 dB、300 Hz 滤波器下 98 dB，三阶截点 +2 dBm（30 kHz 间隔）（MWCircle）。
- **存储**：200 频道（存频率+模式+AGC+ATT+滤波器），锂电池（CR2032）备份；扫描速率 0.5–5 秒/频道可调。
- **接口**：标配 RS-232C（DB-25，4800 baud, 8/N/1），可遥控 36 项功能并回读信号强度等。
- **电源/尺寸**：100/120/220/240 VAC（<35 VA）或 12–16 VDC（<1.9 A @13.8V）；330×130×287 mm，约 9 kg；天线口 50 Ω SO-239 + 600 Ω 弹簧端子。

## 三、电路架构（信号路径）

来源：[shortwaveradio.ch NRD-535 专页](http://www.shortwaveradio.ch/doku.php?id=en:nrd-535)、[Bob Evans 评测](http://bee.mif.pg.gda.pl/ciasteczkowypotwor/%23ham_radio/Other/JRC_NRD-535D_review.pdf)

1. 天线输入 → 35 MHz 低通滤波器 → 继电器切换的 20 dB 衰减器（实测 20.6 dB，仅单档，无 10 dB 中间档）；
2. **变容二极管电子调谐预选器**——七波段双调谐回路，中心频率由微处理器随接收频率连续跟踪（"自动预选"），这是其抗大信号能力强于普通宽带前端接收机的关键；
3. RF 放大 → 第一混频 → **70.455 MHz 第一中频**（高一中频抑制镜像）→ 第二混频 → **455 kHz 第二中频**，噪声消除器（双宽度 NB1/NB2，触发电平可调）在此级工作；
4. 可切换 IF 滤波器组 → **BWC 带宽控制级**（装选件时可将 INTER 带宽从约 2.4 kHz 连续压缩至约 0.5 kHz）；
5. 第三混频 → **97 kHz 第三中频**：IF 陷波器（厂标 -40 dB，WRTH 实测约 25 dB）、PBS 通带平移（±1 kHz；经电脑接口可达 ±2 kHz）、ECSS 同步检波均在此级；
6. 解调输出，AGC 电压亦在 97 kHz 级产生。音频输出 1 W @4 Ω。采用开关电源（[日本 seidensha 页面](http://www.seidensha-ltd.co.jp/~seiden/jrc_NRD-535.html)）。

## 四、NRD-535 与 NRD-535D 的确切区别

**结论：两机主机完全相同，差异仅为三块出厂安装的选件板。**（[RigPix NRD-535D](https://www.rigpix.com/jrc/jrc_nrd535d.htm)："identical to NRD-535 but with the BWC unit (CFL-243), ECSS unit (CMF-78) and Narrow 1 kHz filter (CFL-233) installed from the factory"）

| 选件 | 型号 | 功能 | 535 | 535D |
|---|---|---|---|---|
| ECSS 板 | **CMF-78** | 载波增强可选边带（同步检波） | 选件 | 标配 |
| BWC 板 | CFL-243 / CFL-243W | 带宽连续可调 | 选件 | 标配 |
| 1 kHz 晶体滤波器 | CFL-233 | NARR 档位（RTTY 用） | 选件 | 标配 |

- 标准版 535 主要面向对价格敏感的欧洲市场；**北美市场只销售 535D**（Bob Evans）。价差约 US$400（MWCircle）。
- 早期 535D 的 BWC 为 **CFL-243**（仅 SSB/INTER 位可用）；后 JRC 推出 **CFL-243W** 升级套件，扩展至 AM/WIDE 及除 FM 外所有模式。该套件适用于**序列号 BR56006 以下**的早期北美 535D，定价 $169，内含 BWC 新晶体滤波器、两片 PROM 固件和替换陶瓷滤波器（Bob Evans）。Universal Radio 注明："CFL-243 与 CFL-243W 两种 BWC 板中，CFL-243 不能用于 NRD-535"（[Universal CFL-243 页](https://www.universal-radio.com/catalog/commrxvr/CFL243.html)）。
- **关于"CMK-532"**：在 RigPix、Universal、说明书及所有评测中均查无此型号，应系误记；ECSS 选件板的正确型号是 **CMF-78**。

## 五、ECSS（CMF-78）工作原理与实测表现

- JRC 所谓 ECSS 实为 **PLL 锁相同步检波器**（可选边带），而非经典的手控 BFO+乘积检波 ECSS 电路；板上有专用 IF 放大器与锁相环，坚持用分立元件实现（Bob Evans）。
- 工作在 97 kHz 第三中频，要求调谐在载频 ±1 kHz 以内，约 2 秒内锁定，可锁定至信噪比仅 3 dB 的弱信号；设计配合 WIDE 滤波器使用（MWCircle）。
- 代价：音频失真从 2.7% 升至约 5%（MWCircle）；与 PBS/Notch 同用易失锁啸叫（shortwaveradio.ch）。中波 DX 实测（[dxer.ca，Nick Hall-Patch 等](http://dxer.ca/index.php/our-stuff/10-the-nrd-535d)）：对已可读信号加边带 splatter 的改善明显，但对真正困难的弱信号帮助有限。

## 六、带宽滤波器配置与 BWC 技术

**滤波器档位**（[RigPix](https://www.rigpix.com/jrc/jrc_nrd535.htm)、Universal、Bob Evans）：

- **AUX**：空位默认 12 kHz（-6 dB），可装选件滤波器；
- **WIDE**：标配 4 kHz（-6 dB）/10 kHz（-60 dB）——注意：**首批机器 WIDE 滤波器为 8 kHz，过宽遭批评**，JRC 后改为 5.5 kHz 的 CFL-D6S 陶瓷滤波器并免费提供给老用户（MWCircle、Bob Evans）；
- **INTER**：2 kHz（-6 dB）/6 kHz（-60 dB）SSB 机械滤波器（WRTH 实测实际约 2.6 kHz）；
- **NARR**：1 kHz/3 kHz，需装 CFL-233（535D 标配，535 为选件）；
- **FM**：12 kHz。任意滤波器可用于除 FM 外任意模式。

**选件滤波器**：CFL-218A（1.8 kHz）、CFL-231（300 Hz）、CFL-232（500 Hz）、CFL-233（1 kHz）、CFL-251（2.4 kHz）。

**BWC（带宽连续可调）技术**（[Universal CFL-243W](https://www.universal-radio.com/catalog/commrxvr/CFL243.html)、[说明书](http://www.radiomanual.info/schemi/Surplus_Radioamateur/JRC_NRD-535_DG_user.pdf)、Bob Evans）：
- 电路构成：**两个 BWC 混频器 + 两个本振（直接数字合成器）+ 中心频率 400 kHz 的晶体滤波器**，以 10 Hz 步进电子压缩所选 IF 滤波器的带宽，且不改变通带中心频率；
- CFL-243W 实测裙边规格：WIDE 5.53 kHz→2.00 kHz、INTER 2.22 kHz→0.49 kHz（-6 dB 值）；
- 这实际上是 1998 年后继机 NRD-545 全 DSP 连续带宽（40 Hz–10 kHz）的模拟/DDS 前身。

## 七、主要专业评测结论摘要

- **WRTH 1992**（[MWCircle 存档](https://mwcircle.org/legacy-receiver-reviews/receiver-review-nrd-535/)）："excellent value for the serious shortwave listener"，唯互调与动态选择性略有保留；缺陷：S 表在 S5（3 µV）以下不动、陷波仅 25 dB、衰减器只有一档、显示屏自身辐射噪声比 525 恶化约三倍。
- **Bob Evans 长评**（[PDF 存档](http://bee.mif.pg.gda.pl/ciasteczkowypotwor/%23ham_radio/Other/JRC_NRD-535D_review.pdf)）：初期机型有 AM 带宽过宽、AGC 过冲、BWC 限模式、说明书糟糕四大缺陷，JRC 纽约办公室逐一整改；与 NRD-525、Drake R-8 详尽的 A/B 对比（535D 全套约 $1879 vs R-8 约 $1009）。
- **Popular Communications**：1991 年 12 月号第 29 页评测（RigPix 记载）；Passport 1992 版列出 535D $1699 / 535 标准版 $1199（[manuals.plus 存档页](https://manuals.plus/m/ae0ea2c0e9df17d9bd7c664f059ee42b464cb7388f8fb15d08ec8ec2d7bb33d5)，检索摘要所见，页面本身被反爬拦截未能全文核对）。
- **shortwaveradio.ch**（[NRD-535 专页](http://www.shortwaveradio.ch/doku.php?id=en:nrd-535)）：发布后迅速成为各评测机构的"参考接收机"，直到 NRD-545 与 Watkins-Johnson HF-1000 等 DSP 机登场；二手购买务必核实选件板是否齐全。
- **dxer.ca 中波 DX 评测**：前端虽有跟踪预选，强台环境下仍可测到三阶互调产物（本地 1200 kHz 在 1330 kHz 处可闻），中波表现"非顶级"；推荐 2 kHz 滤波器 + BWC + PBS + 关 AGC 骑 RF 增益 + SSB 检波作为 DX 手法。
- **eHam 用户群**（[17 条评测](https://www.eham.net/reviews/detail/6090)）：普遍认为灵敏度、安静度、人机工程出色；BWC 在 AM 模式下也可用是广受好评的特点。

## 八、备注与存疑点

- **生产截止年份**：RigPix 记 535 为 1991–1997、535D 为 1991–1998，而 MWCircle 称 535D 产至 1998 年夏——即标准版 535 约 1997 年先行停产，535D 延续到 1998，与任务描述"1991–1997 左右"基本吻合。
- **第一中频精确值**：多数来源为 70.455 MHz，Universal 规格页写 70.45399 MHz，Bob Evans 文中出现 70.445（疑为笔误）；第三中频各来源一致为 97 kHz。
- 其它选件：CMH-530 RTTY 解调板（与 525 通用）、NVA-319 有源滤波音箱、ST-3 耳机、6ZCJD00350 RS-232 线、CKJ-61 mark/space 线（RigPix）。
- 检索中 **未发现任何"CMK-532"型号**，确认 ECSS 板为 CMF-78。
