# IC-R9000 现代化改造路线研究报告

> 2026-09-27。基于 5 路并行深度调研（原始记录见 `REF/09`–`13`），结合前一轮基础研究（`REF/01`–`04`）。
> 目标命题：把 IC-R9000（1989，全模拟四次变频，0.1–2000 MHz）提升、改造、现代化到"当今领先旗舰机水平"。

## 〇、先给结论

1. **射频链的硬指标追不上现代旗舰，且无人能追**——窄间隔动态范围（71 dB@5kHz vs 现代 96–110 dB@2kHz）、本振相位噪声（128 vs 145–156 dBc/Hz）、阻塞（129 vs 147–151 dB）这三项由 1989 年的合成器与前端架构决定。**全球公开文献中没有任何成功的本振/roofing filter 改造案例**，重做成本远超机器价值。
2. **但"使用体验与功能"可以全面达到甚至超越现代旗舰**——通过 SDR 外挂（全景瀑布、数字滤波、同步检波、降噪、录音、数字模式解码），加上 LCD 化、散热改造和彻底翻新，R9000 可以成为一台"1989 年的顶级模拟前端 + 2026 年的数字解调终端"混合体。这正是荷兰国家监听局 PAN-2000 系统 30 年前就验证过的路线。
3. **正确定位**：改造后的 R9000 是台站里的"VHF/UHF/频谱监测 + 情怀旗舰"，HF 极限 DX 交给现代 SDR（哪怕 $300 的 IC-7300 窄间隔 DR 都比它高 26 dB）。两者协同而非替代。

## 一、差距量化：离"现代旗舰"到底差多少

全部同实验室（Sherwood）可比数据：

| 指标 | IC-R9000 (1989) | IC-R8600 / IC-7760 | FTdx-101D / TS-890S（天花板） | 差距 |
|---|---|---|---|---|
| 底噪 | -131 dBm | -142（开预放） | -141 | ~10 dB（HF 上被大气噪声淹没，**实际无感**） |
| 本振相位噪声 @10kHz | 128 dBc/Hz | 144–148 | 154–156 | **16–28 dB** |
| 阻塞 @100kHz | 129 dB | 125 | >147–151 | ~20 dB |
| 窄间隔 DR | 71 dB @5kHz | 98–107 @2kHz | 105–110 @2kHz | **26–39 dB 且间隔更窄** |
| 宽间隔 DR @20kHz | 93 dB | 98–109 | 106–111 | 12–18 dB |

关键洞察：
- **底噪差距在 HF 是伪命题**——大气噪声远高于 -131 dBm，R9000 的灵敏度今天依然过剩。
- **真正的代差在近端动态范围和相位噪声**：密集强信号环境下（ contest、广播频段夜间），现代机的优势是决定性的。
- 有意思的参照：**Icom 自家 2003 年的 R9500 旗舰也被相位噪声限制**（Sherwood 标 `f`），直采 SDR 时代才真正解决。这不是 R9000 一台机器的问题，是整个模拟合成器时代的天花板。

## 二、改造路线图（按收益/风险排序）

### 第 0 阶段：恢复到出厂性能（一切的前提）

老机不恢复健康，任何升级都是空中楼阁。

| 项目 | 做法 | 成本 | 依据 |
|---|---|---|---|
| 散热改造 | 后面板加 120mm 低速风扇（取电自背板 12V 插座），或 Sherwood 风扇面板方案 | <$30 | 多案例实证；KD5OEI："Icom 应该加风扇，你应该加风扇" |
| 电容 | 至少换 REG 电源 + DC-DC 变换器单元全部电解（105°C 品）；全机 recap 用 Klondike Mike 的 197 只套件，但注意"盲换全机有风险"的反对意见，**建议按故障域分段换** | 套件 ~$100 级 | Icom 官方 FAQ；YO9FZS |
| 记忆电池 | BR2032 **不断电更换**（并接 3V），另换 SRAM 可用通用 32k×8 | <$10 | groups.io 案例 |
| 已知坏点 | CRTC 板 C11、CRT 板 C407/C410、编码器清洗重润滑、N 座中心针检查 | <$20 | bunkerofdoom；官方 FAQ |
| 整机重调 | 按维修手册做频谱中心/PLL/鉴频器校准 | 0 | 官方 FAQ + 手册 |

### 第 1 阶段：显示与人机界面现代化

- **CRT → LCD**：成熟方案任选——eBay 成品模块（~$136）、阿里巴巴 VS Displays 套件、或 JA4FUQ 式 VGA 板+5"LCD 散件 DIY（可逆、省电 1A、减重 1.7 kg，本地存档 `RIG/ic-r9000.html` 有完整施工记录）。日本 TBHD 提供付费施工。
- **S 表灯泡换 LED**（Ham Radio Doctor 视频有实录）。
- **CI-V 现代化**：FTDI USB CI-V 线（Valley Enterprises / bluemax49ers），OmniRig Poll ≤100 ms。

### 第 2 阶段：SDR 外挂（本方案的核心，一次补齐四大短板）

R9000 是 IF 外挂的**理想宿主**：10.7 MHz 中频全波段恒定、背板自带 IF OUT、纯接收机无需 PTT 切换。

**推荐架构**：

```
天线 → R9000 前端（0.1–2000 MHz 模拟预选/变频）
          │
          ├─（原厂通路）→ 模拟解调 → 喇叭/音箱（可串 bhi DSP）
          │
          └─ IF UNIT 第二混频器后 tap（滤波器前，宽频谱）
              → IFace / JFET 高阻缓冲板（50Ω 输出，BNC）
              → SDRplay RSP1A / RTL-SDR V3（带 TCXO）
              → PC：HDSDR 或 SDR Console（勾 Invert Spectrum！）
                  ├─ 全彩全景瀑布（替代/超越 CRT 频谱仪）
                  ├─ ECSS 同步检波 + AFC（R9000 完全没有的功能）
                  ├─ 任意带宽数字滤波 + 自动陷波×10
                  ├─ 数字降噪 / 噪声消隐
                  ├─ 校准过的 dBm S 表
                  └─ RF/IF 录音、数字模式解码
          CI-V（USB）→ OmniRig 双向联动：点瀑布=R9000 跳频，转旋钮=瀑布跟随
```

**关键工程要点**（全部来自实测案例）：
1. 取点选在**第二混频器后、10.7 MHz 滤波器前**（TSP 给了 R9000 专用取点图）——滤波器前才有宽频谱。
2. **必须高阻缓冲**（JFET 跟随器/IFace 板），直接 50Ω 加载会把 IF 吸哑（Drake R-4B 的教训）。
3. R9000 的 IF **频谱是反转的**：HDSDR 勾 "Swap I/Q"，SDR Console 勾 "Invert Spectrum"，硬件解码器（AR-DV1）设 IF DIR=REV。
4. 接线用 **BNC-BNC 射频线**，别用 RCA 视频线（10.7 MHz 损耗大）；原厂 RCA IF 口位置拾取杂散，重度玩家可学荷兰 RCD 把 IF 输出改到直焊 BNC。
5. 用 WWV 10 MHz 做主机与 SDR 的频率互校；SDR 的 USB 线加磁环防地环路噪声。
6. 简易起步方案：**先不动刀**——背板 IF OUT 直插 SDR 就能玩（带宽受限于所选滤波器，最大约 230 kHz），验证链路后再做机内 tap。

**这一阶段补齐的功能对照**：

| R9000 原生短板 | 外挂后 | 评价 |
|---|---|---|
| 无同步检波 | HDSDR ECSS+AFC 自动锁载波 | **补齐最彻底**（也可选 Sherwood SE-3 纯硬件方案，$695+安装） |
| 固定 4 档滤波 | 任意带宽 + 10 陷波 | 超越多数现代机 |
| 无数字降噪 | HDSDR NR/NB，或 bhi 硬件（40 dB） | 补齐 |
| CRT 频谱 ±100 kHz 单色 | 全彩瀑布数 MHz 宽 | **超越** |
| 无录音/解码 | RF/IF 录音、DMR/DMR/Tetra 解码 | 补齐 |

### 第 3 阶段：射频链增强（能做的与不能做的）

**有先例可做的**：
- **AM 第 4 档滤波**：Sherwood 的滤波逻辑板改装，启用 SSB 专用的 6 kHz 滤波器给 AM（AM 变为 15/9/6/3 kHz 四档）。
- **SE-3 同步检波**（纯硬件路线，不想开 PC 时）：Sherwood 有 R9000 专用 455 kHz 下变频+缓冲板。
- **AGC 特性优化**：荷兰 RCD 改 AGC 电路的思路（细节未公开，但证明可行）。
- **使用技巧白捡的性能**：FM DX 时手动选 FM-W 30 kHz 而非 WFM 150 kHz，可获约 **14 dB S/N 改善**（groups.io）。

**无人做成、仅理论可行的（前沿空白）**：
- **Roofing filter 替换**（把 HF 一中频 20 kHz MCF 换成 4–5 kHz 晶体滤波器 + 高动态补偿放大）：IC-781 的 Inrad 套件证明该思路能改善 IMD DR **7–14 dB**，但需按 R9000 的 48.8 MHz 一中频定制晶体，且与宽频谱显示/WFM 模式存在架构冲突。若想成为"第一个做成的人"，这是最有价值的方向。
- **本振相位噪声改进**：需重做覆盖 2 GHz 的 DDS+PLL 合成器并与 CI-V 深度耦合——**工程上等于重造一台接收机，不建议**。
- **GPSDO 外参考注入**：无公开案例；PLL B 单元基准理论上可改注入式，属空白。

**明确不该做的**：盲换全机 197 只电容而不分段验证（有引发新故障的实录警告）；为提高 CRT 灯丝电压"复活"CRT（YO9FZS 明确反对）。

### 第 4 阶段：扩展玩法（R9000 的独有优势区）

这些是**现代 HF 旗舰做不到、只有 R9000 能做**的：
- **QO-100 卫星**（10.489 GHz 下行）：PLL LNB 变频到 739 MHz → R9000 直收 → IF OUT 接 SDR 解调。
- **GOES/Meteosat 1691 MHz 气象传真**：原生覆盖直收。
- **航空/海事/2 m/70 cm 监测**：13 信道/秒扫描 + 1000 存储 + SDR 瀑布。
- **模拟电视解调**（CRT/LCD 直接显示 ATV 画面）——数字时代绝版功能。

## 三、最终形态与诚实的期望管理

| 维度 | 改造后能达到 | 不能达到 |
|---|---|---|
| 功能/体验 | **达到或超越现代旗舰**（瀑布、同步检波、数字滤波、降噪、录音、解码、遥控） | — |
| HF 极限 DX 性能 | 恢复到 1989 出厂水平（当年世界一流） | 窄间隔 DR/相噪/阻塞**永远差现代旗舰 20–30 dB** |
| VHF/UHF/微波 | 0.1–2000 MHz + 瀑布 + 数字解码，**仍有现实价值** | — |
| 可靠性 | 电容/散热/显示翻新后再战 20 年 | CRT 原件死路一条，必须 LCD 化 |

**预算估算**（DIY 路线）：风扇 $30 + 电容套件 ~$100 + LCD ~$140 + IFace 缓冲板 ~$60 + RTL-SDR $35 + CI-V USB 线 $25 ≈ **$400 以内**，即可获得：焕然一新的可靠性 + 现代旗舰级的操作体验 + 保留全部模拟黄金时代的手感与音质。Sherwood 全套代工（滤波+SE-3）约 $1,000+。

**终极建议**：R9000 负责 VHF/UHF/频谱监测/卫星/情怀与音质，旁置一台 Airspy HF+ Discovery（$200 级，MDS -141 dBm、BDR 116 dB）负责 HF 极限 DX——这套组合的总成本和占地，都低于任何一台现代旗舰，且两条链路可互为备份、互为对照。
