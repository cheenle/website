## 1. 背景与问题

2026-09-05 发布的《Seven Billion Tokens, Dissected / 七十亿 token 的全程拆解》是一篇
账本先行的案例解剖（19 节 / 6 卷 / 3 附录，EN + ZH，约 30 分钟）。发布一周后（2026-09-12）
重新勘察发现三类问题：

1. **数字过时**：`mrrc_modern` 已从 v1.12.1 走到 **v1.14.3**（5 天 4 个版本）；`website`
   仓 +31 commits；主力模型已切换。
2. **门面数字三层错**：已发表的 `7,007,437,567` 同时**虚高**（claude-code 行口径把同一
   API 响应重复计入约 2.7×）、**虚低**（Hermes `485,213,348` 被记作“未记录”——只查了
   `messages` 表而漏了 `sessions` 表；AgnesCode `82,931,675` 与 DeepSeek Harness
   `10,931,069` 完全未登）、且**会漂移**（保留期使 claude-code 比一周前低 `679,899,086`；
   观察者效应使同一脚本两次运行不同）。重算后的真实值：
   **`7,353,156,771`（行口径）/ `5,644,079,638`（去重口径）**。
3. **结构不适合查询**：账本明细、模型年鉴、测量边界是"查询型"内容，混在叙事长文里
   迫使读者读完全文才能查一个数字。

## 2. 目标读者与成功标准

**主读者**：想用 AI 做业务的**技术负责人 / 独立开发者**（次要读者：HAM 与开源同行、
更广的 AI 工程读者）。

**成功标准**（三条，缺一即未达标）：

1. **更有价值**：读者能拿走至少一个别处读不到的判断——本系列的第一个是
   「证据必须被快照，不能被累计」。
2. **更准确**：所有数字可复核、标注测量窗口、双口径不混；标题里的"七十亿"被显式
   解释为快照读数而非累计量。
3. **更有实践意义**：主文给出因果链，分册 C 给出可照抄的清单/模板/决策规则。

| pi 新模型 | `glm-5.3-flash`(745)、`deepseek-v4-flash-vision-exp`(85)、`qwen3.8-flash`(1227) | 年鉴须补 |
| mrrc_modern | **v1.14.3**（09-11）；v1.14.0→v1.14.3 五天四版 | 版本与测试数须复核 |
| 约束注册表 | ft710 17 / modern 21 / ft8 14 = **52（一周未增）** | 增长曲线走平，须如实写 |
| modern 返工率 | 09-05 后 38 提交中 17 个 fix ≈ **44.7%** | 印证"返工弧形"论断 |

**关键机制**：claude-code 日志有保留期（`~/.claude/.last-cleanup`），其余工具未见清理。
因此**每个 harness 必须标注自己的测量窗口**，跨时点比较只在同口径内成立。

**观察者效应（实测）**：census 测量的机器上，**执行本次测量的会话本身也在被测量**。
同一条命令相隔 12 分钟得出两个 pi 总额（`1,874,576,102` → `1,882,914,800`，差 `8,338,698`），
差额来自本次会话自己写入的 token。

**“未记录”的宣布标准（本改新增红线）**：任何 harness 在被标为“未记录”之前，必须逐表
列出查过的表与列；否则不得下结论。本项目就因为只查 `messages` 而漏了 `sessions`，
导致已发表账本少算 4.85 亿。

## 7. 数字口径与事实归属

### 7.1 双口径陈述

| 陈述 | 值 | 性质 |
|---|---|---|
| 09-05 首发记录值（行口径） | 7,007,437,567 | 历史快照，**今日无法复现** |
| 09-12 重跑（行口径） | **7,353,156,771**（+345,719,204） | 包含三源补登 |
| 09-12 重跑（去重口径） | **5,644,079,638** | **唯一可比口径** |

**两个方向的误差必须分开陈述**：

- **虚高**：claude-code 行口径把同一 API 响应的分块重复计入，放大约 2.7×；去重后
  仅 `818,520,401`
- **虚低**：漏登 Hermes `485,213,348` / AgnesCode `82,931,675` / DeepSeek Harness `10,931,069`
- **漂移**：保留期使 claude-code 比一周前低 `679,899,086`；观察者效应使同一脚本两次运行不同

**排序约束**：census 重算必须是实现计划的**第一个任务**，其余所有任务以它的输出为输入；
在 census 落地前不得改动任何 HTML 中的数字。

标题的“七十亿”由“错误”变成了“低估”：真实值 73.5 亿，而其不确定性恰恰是本文的主题。

### 7.2 可比性规则（写入分册 A `boundaries`）

1. 每个 harness 必须标注自己的**测量窗口起止**
2. 跨时点比较**只在同口径内**做（行 vs 行、去重 vs 去重）
3. 总额**不是单调量**；下降必须显式标注，不得掩饰
4. 沿用“估算/未记录**不并入**已记录合计”纪律（iFlow ≈2.47 亿估算）；
   **并新增“未记录”的宣布标准**：任何 harness 在被标为“未记录”前，必须逐表列出查过的
   表与列——本轮就因只查 `messages` 而漏了 `sessions`，少算 4.85 亿
5. **观察者效应（实测新增）**：census 测量的机器上正在运行的**执行本次测量的会话**，
   本身就在被测量。实测：同一条命令相隔 12 分钟得出两个 pi 总额
   （`1,874,576,102` → `1,882,914,800`，差 `8,338,698`），差额来自本次会话自己写入的
   `13,082,587` tokens（`~/.pi/agent/sessions/--Users-cheenle-HAM-website--/`）。
   因此**每个 census 值必须携带一个截止时间戳**，否则不可复现。

### 8.2 中文版精确性修订规则

1. **单位统一**：正文 token 量一律「亿 tokens」（`7.1B` → 「71 亿 tokens」）；
   `B`/`M` 只在模型名或原始口径括注中出现
2. **不造词**：不使用"沉淀地"等自造词作术语（现文 §02 标题即用了）→ 改「知识的载体」
3. **不夹生**：`usage`/`cwd`/`payload` 等字段名保留 `<code>`，叙述句中用中文
4. **引号与空格**：中文用「」，代码用 `<code>`；中英文之间保留半角空格
5. **首现加注**：`harness`、`token`、`SDD`、`FDE`、`PTT`、`CAT` 首次出现给全称或中文注解
6. **动词精确**：**委托**（delegate，人→agent）、**拦截**（block，门禁动作）、
   **沉淀**（settle，知识落到载体）、**裁决**（verdict，人保留的判断）四个动词全文严格
   分工，不混用
