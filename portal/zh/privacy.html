隐私政策

最后更新：2026 年 8 月 12 日

摘要

本网站（www.vlsc.net）是一个纯静态信息站。它没有用户账户、没有登录、没有评论表单、也没有新闻通讯。简而言之：我们几乎不收集你的任何信息，我们所收集的一切都只是标准 Web 服务器的常规运行数据。

本网站不收集的内容

  • 不收集你主动提供的数据 —— 本网站没有表单、没有注册、没有支付流程、也没有邮箱订阅。
  • 无第一方分析 —— 我们不运行 Google Analytics、Matomo 或任何我们自己的访客追踪脚本。
  • 无第一方 Cookie —— 本网站本身不设置 Cookie。

服务器日志

Web 服务器（nginx）记录标准的访问日志：请求 IP 地址、请求的页面、HTTP User-Agent 字符串以及时间戳。这是任何 Web 服务器的正常运行方式，用于安全（检测滥用）、诊断和汇总的流量统计。日志不会出售或与第三方共享，其中除任何浏览器访问任何网站都会发送的内容外，不包含其他个人信息。

第三方广告 —— Google AdSense

本网站可能展示由 Google AdSense 提供的广告。作为第三方供应商，Google 使用 Cookie 及类似的存储技术，根据你之前对本网站及其他网站的访问来投放广告。

  • DoubleClick DART Cookie —— Google 使用 DoubleClick Cookie（及类似标识符）来投放相关广告并衡量广告效果。
  • 个性化广告 —— Google 可能使用收集到的数据投放个性化广告。你可以在 Google 的广告设置 中选择退出个性化广告。
  • Google 如何使用数据 —— 你可以在 policies.google.com/technologies/partner-sites 阅读 Google 在 AdSense 网站上的数据使用方式。
  • Google 隐私政策 —— policies.google.com/privacy。
由于 Google AdSense 是第三方服务，它使用的 Cookie 及其他存储受 Google 自己的政策约束，而非我们的。阻止或删除第三方 Cookie（或启用"请勿追踪"）可能减少你看到的广告数量，但不会影响本站内容。

其他第三方服务

本网站会加载以下第三方资源，作为正常 Web 请求的一部分，它们可能会看到你的 IP 地址：

  • Google Fonts（fonts.googleapis.com / fonts.gstatic.com）—— 用于 Inter 与 JetBrains Mono 字体。
  • Font Awesome（cdnjs.cloudflare.com）—— 用于图标。
  • GitHub（github.com）—— 指向项目仓库的链接；我们不在页面上加载 GitHub 脚本。

在线演示

部分页面链接到托管在 radio.vlsc.net 的在线电台演示。如果你打开演示，你将直接使用演示服务器；与任何 Web 服务一样，它可能记录标准的连接日志。关闭演示不会在本站留下任何东西。

你的选择与联系

如果你对本政策有疑问，或者你所在司法管辖区（如欧盟/欧洲经济区或加州）赋予你特定的隐私权利且你希望行使这些权利，请联系我们：

  • 邮箱：contact@vlsc.net
  • GitHub：github.com/cheenle

政策变更

如果本政策发生变更，页面顶部的"最后更新"日期会被修订。重大变更将在各项目的 GitHub 仓库中说明。
