# JRC NRD-535（非 D 版）深度研究报告

> 调研时间：2026-09。来源覆盖 JRC 官方专栏、RigPix、Radio Netherlands/MWC（WRTH）评测、Bob Evans 长评、Sherwood、shortwaveradio.ch、N9EWO、Kiwa/Fenu-Radio、日本 TBHD 修理店与雅虎拍卖成交数据、YouTube 视频档案，以及本地存档 `../jrc_NRD-535.html`（JA4FUQ 实测报告）。

## 一、定位与历史

- **JRC 最后一台纯模拟旗舰接收机**（后继 NRD-545 转 DSP），谱系 NRD-505 → 515 → 525 → **535**。1990/1991 年发布，标准版约产至 1997、535D 至 1998。
- 获 **1991 年度 WRTH"最佳通信接收机"行业奖**；发布后迅速成为各评测机构的"参考接收机"，直到 DSP 机登场。
- 当年价格：535 约 US$1,200 / £1,750；535D 约 US$1,690 / £1,995（贵约 $400）。**北美只卖 535D**，标准版 535 主要面向价格敏感的欧洲市场。
- **JRC 已于 2017 年终止全部业余机型修理支持**，现在维修靠 TBHD 等民间店和社群互助。

## 二、你的非 D 版与 535D 的确切区别

**主机完全相同，差异仅为三块出厂选件板**：

| 选件 | 型号 | 功能 | 535（你的） | 535D |
|---|---|---|---|---|
| ECSS 板 | **CMF-78** | 载波增强可选边带（PLL 同步检波） | 选件 | 标配 |
| BWC 板 | **CFL-243 / CFL-243W** | 带宽连续可调（10 Hz 步进） | 选件 | 标配 |
| 1 kHz 晶体滤波器 | CFL-233 | NARR 档（RTTY/窄带） | 选件 | 标配 |

- 注意：早期 535D 的 CFL-243 仅限 SSB/INTER 位用 BWC；**CFL-243W 才支持 AM/WIDE 等全模式**（适用序列号 BR56006 以下机器的升级套件当年卖 $169）。CFL-243 不能用于 535 标准版。
- 补装成本警示：日本市场 CFL-243 BWC 单板成交 **14,000–35,000 日元**，CMF-78 ECSS 板约 4,801 日元——裸机补齐选件不划算，买时确认已装选件最划算。
- 另有第三版本 **NRD-535V**（仅带 ECSS）。
- "CMK-532"型号查无实据，ECSS 板正确型号是 CMF-78。

## 三、核心规格

| 项目 | 参数 |
|---|---|
| 频率范围 | 标称 90 kHz–30 MHz（实测可调至更低，77.5 kHz 授时台可收） |
| 架构 | 上变频三次超外差：**70.455 MHz / 455 kHz / 97 kHz** |
| 合成器 | DDS+PLL 混合，**1 Hz 步进**；±2.5 ppm（选件 CGD-135 TCXO 达 ±0.5 ppm） |
| 灵敏度 | SSB/CW 1.6–30 MHz **0.32 µV**（10 dB S/N）；AM 2 µV；FM 0.5 µV |
| 动态范围 | 厂标 106 dB@300 Hz；**WRTH 实测 88 dB@2.6 kHz、98 dB@300 Hz**；三阶截点 +2 dBm@30 kHz |
| 存储 | 200 频道（CR2032 锂电池备份） |
| 接口 | 标配 RS-232C（4800 baud，36 项遥控）；天线 50Ω SO-239 + 600Ω 弹簧端子 |
| 电源/体积 | AC 100–240V 开关电源 或 12–16 VDC；330×130×287 mm，约 9 kg |

**信号路径亮点**：天线 → 35 MHz LPF → 继电器 20 dB 衰减（仅一档）→ **变容二极管七波段跟踪预选器**（微处理器随频率连续调谐，抗大信号的关键）→ RF 放大 → 70.455 MHz → 455 kHz（NB 在此级）→ BWC 级 → 97 kHz（Notch、PBS ±1 kHz、ECSS、AGC 均在此级）。

**滤波器档位**：WIDE 4 kHz（首批 8 kHz 过宽，JRC 后免费换 5.5 kHz CFL-D6S）/ INTER 2 kHz（实测约 2.6 kHz 机械滤波器）/ NARR 1 kHz（需 CFL-233）/ AUX 空位默认 12 kHz 可装选件（CFL-218A 1.8k / CFL-231 300 Hz / CFL-232 500 Hz / CFL-251 2.4k）。

**BWC 原理**：两个混频器 + 两个 DDS 本振 + 400 kHz 晶体滤波器，以 10 Hz 步进压缩带宽且不动通带中心——是 NRD-545 全 DSP 连续带宽的模拟前身。CFL-243W 实测可把 INTER 从 2.22 kHz 压到 0.49 kHz。

**ECSS（CMF-78）**：PLL 锁相同步检波（非经典 BFO ECSS），97 kHz 级工作，±1 kHz 内约 2 秒锁定、可锁 3 dB 信噪比的弱信号；代价是失真 2.7%→5%，与 PBS/Notch 同用易失锁。JA4FUQ 实测评价："白天用不出区别，夜间远距离、拥挤且衰落大时确实有效"。

## 四、评测口碑

- **WRTH/MWC**：高灵敏度、抗强信号好、"对认真的短波收听者物有所值"；批评点：S 表 S5（3 µV）以下不动、Notch 实测仅 25 dB（厂标 40）、衰减器只有一档、**显示屏辐射噪声比 525 严重约 3 倍**。
- **Sherwood 实测**：底噪 **-135 dBm**（优于 R9000 的 -131）+ 跟踪预选器；窄间隔 DR 70 dB（与 R9000 的 71 dB 同水平）。
- **eHam 长期约 4.6/5**：安静、灵敏、人机工程出色；BWC 在 AM 也可用广受好评。
- **N9EWO 批评视角**：525 的中频嘶声解决了但换来数字噪声；认为同步检波性能平庸。
- **dxer.ca 中波实测**：强台环境下仍可测到三阶互调，中波 DX 非顶级；推荐手法：2 kHz 滤波 + BWC + PBS + 关 AGC 骑 RF 增益 + SSB 检波。

## 五、通病与维修（重点）

1. **VFD 荧光屏变暗/熄灭（最著名通病）**：先暗后灭，JRC 已无备件，坏了机器退化为"只能电脑遥控"。可尝试换显示单元 DC-DC 电路的 4 只高压（35–50V）电解电容，成功率有限。注意：TBHD 有案例"频率只显示一瞬即灭"最终诊断为 **CPU 参数异常**而非显示管——显示故障别只盯 VFD。
2. **电解电容老化**：全机 recap 已是标准维护。Klondike Mike's 有专用套件：**基础 70 只，有 BWC/ECSS 再加 40 只**（Rubycon/Nichicon/Panasonic）。最明确的故障点是显示 DC-DC 电路。
3. **AGC 过冲（官方承认的设计缺陷）**：突发强信号导致瞬时丢信号、AGC OFF 切换爆音。JRC 当年提供 IF 板（CAE-227A）割线改版；第三方修法：Thomas Nilsson AVC 电阻改法（R105 短至总阻 500 kΩ、R103/R104 改 100 kΩ）、Kiwa 改装包含 AGC 修正。
4. **PLL/DDS/VCO**：TBHD 实录——开机无声多为 **DDS 单元故障**；**自行更换 VCO 内电容参数不当会导致 18 MHz 以上失锁**（换件需严格按规格）。
5. **记忆电池**：CR2032，额定寿命 **5 年**，所有现存机器都已超期——趁未死更换（参考 Bob Evans 评测的更换说明，操作简单）。
6. **调谐旋钮**：旋转磁编码器本身可靠；常见问题是**旋钮太轻/惯性大**（JA4FUQ 也吐槽），民间修法是刻度盘与轴间垫毡垫圈增加阻尼。
7. **按键**：前面板小开关接触不良多（酒精清洗可解决，通用件可购）；字符磨损个案存在。
8. **设计性缺陷（改不掉）**：RF 板位置导致 8–10 MHz 以上拾取机内数字噪声；低频段（50–250 kHz）RFI 明显。
9. 备件：意大利 CSY & SON 有 JRC 欧洲代理仓库的新备件库存（含 CDE-705 显示单元、CPU 板等，€350 级清单）。

**维修资料**：维修手册 [ManualsLib](https://www.manualslib.com/manual/1034293/Jrc-Nrd-535.html) / [rigreference PDF](https://rigreference.com/storage/manuals/jrc/JRC%20NDR-535D%20service-manual.pdf--5c13f15d5f5c72.99943403.pdf)；用户手册 [RadioManual.eu](http://www.radiomanual.info/schemi/RX/JRC_NRD-535_user.pdf)；社群 groups.io [JRCAmateurSWL](https://groups.io/g/JRCAmateurSWL)。

**改装汇总**：Kiwa（音频高频响应 + AGC 修正 + "Blue Dot" 6.8 kHz 宽带滤波器）；Sherwood（IF 板改动，原厂滤波器抑制 +20 dB）；Lowe（英国，AGC/ECSS/音频）；Thomas Nilsson/Dallas Lankford（AVC、滤波器级联）；Gilfer（换 FET 降噪）。

## 八、JA4FUQ（本地存档）实测要点

见 `../jrc_NRD-535.html`：他特意选了**加装 ECSS + 300 Hz/3 kHz 两支滤波器的 535**（"与 535D 只差 BWC"）。一手数据：
- 整机与主板仅 4 组连接器，拆卸极简；前面板按键酒精清洗即可
- **S 表标定实测（7.2 MHz）**：9 dBµV→S3、15→S5、25→S7、36 dBµV→S9（S9 略宽松）
- **灵敏度实测满足厂标**：230 kHz/1.8 MHz 处 SSB 0.25 µV（S/N 10–11 dB）
- 主旋钮惯性太大是公认槽点（垫毛毡解决）
- INTER 位实测装的是国际 MF-31C 机械滤波器（2.4 kHz），WIDE 为 NTK CLF-D8 陶瓷
