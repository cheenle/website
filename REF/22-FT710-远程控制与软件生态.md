# FT-710 远程控制与软件生态 — 深度调研报告

调研共读取/检索 20+ 个独立来源（Yaesu 官方 4 份、wfview 官方及论坛 4 份、Hamlib 3 份、第三方软件文档 6 份、经销商/媒体若干）。以下所有数字均出自实际读到的页面。

---

## 1. 硬件接口全景：FT-710 没有 LAN 口

Yaesu 官方产品页确认的后面板接口：**两个 USB 口（Type-A 和 Type-B）**、EXT-DISPLAY（DVI-D）、SD 卡槽；官网明确写着 "Remote Operation with Network Remote Control System (**Available in the near future**)"（产品页文案长期未更新），网络远程**必须靠外置 SCU-LAN10**，机身无任何以太网口。([yaesu.com FT-710 产品页](https://yaesu.com/product-detail.aspx?Model=FT-710&CatName=HF%20Transceivers/Amplifiers))

单根 USB 线（Type-B）向电脑呈现**三/四个设备**（官方 CAT 手册 + wfview 文档交叉验证）：

| 设备 | 芯片 | 功能 |
|---|---|---|
| Enhanced COM Port（CAT-1） | Silicon Labs CP210x 双 UART | CAT 命令，38400 bps（菜单可改） |
| Standard COM Port（CAT-2） | 同上第二路 | PTT / CW keying / 数字模式，或第二路 CAT，默认 4800 bps |
| USB Audio CODEC | C-Media（本站博客已逆向） | 44.1 kHz 收发音频 |
| FT4222 SPI 桥 | FTDI FT4222H（USB ID `0403:601c`） | 频谱/scope 数据（非用户文档化，见 §4） |

来源：[FT-710 CAT Operation Reference Manual (2306-C)](https://www.yaesu.com/Files/4CB893D7-1018-01AF-FA97E9E9AD48B50C/FT-710_CAT_OM_ENG_2306-C.pdf)、[wfview FT-710 Setup](https://wfview.org/wfview-user-manual/yaesu-ft-710-setup/)。

另有第三路 **CAT-3**：TUNER/LINEAR 口可切为 5V TTL 串口 CAT（38400 bps），需选装 CT-58 线，且**与外接天调/功放互斥**（CAT 手册）。

## 2. CAT 命令集：与 FT-991A 几乎同族，与 FTDX10/IC-7300 的关键差异

**协议本体**（CAT OM 2306-C）：两字母 ASCII 命令 + 定长参数 + 分号终结符，如 `FA014250000;`（VFO-A=14.25 MHz）；分 Set/Read/Answer 三类。异步 8N1，CAT-1/CAT-3 为 38400 bps、CAT-2 为 4800 bps（均为出厂默认，CAT-1 可改——SimpleHRR 教程即把它改成 9600）。

- **与 FT-991A 的关系**：Ham Radio Deluxe 官方知识库（2023-03-28）明说 "**FT-991A 和 FT-710 命令完全一致，只多 3 条 AESS 功能的新命令**"，HRD 因此让 FT-710 用户直接套 FT-991A profile。注意：该知识库文章**标题**写的是 "use the FTDX10 radio profile"，**正文**却是 FT-991A——同页自相矛盾，以正文为准（正文明确到"复制 FT-991A、改名、加 3 条命令"的实现细节）。([HRD 支持文档](https://support.hamradiodeluxe.com/support/solutions/articles/51000337439-support-for-yaesu-ft-710))。这 3 条 AESS 命令只对 **AESS 版**有意义（Field 版无 SP-40 外扬声器，见 §9）。
- **与 FTDX10 的差异**：FTDX10 同为 Yaesu ASCII CAT，CAT RATE 可选 4800/9600/19200/38400，默认 38400（[FTDX10 操作手册](https://static.dxengineering.com/global/images/instructions/ysu-ftdx-10_zx.pdf)）。**最大差异不在命令而在频谱路径**：wfview 2.20 公告明确 "由于电台侧约束，scope 数据目前**仅 FT-710** 支持"（FTX-1 都不行）——即 FT-710 的 FT4222 USB SPI 频谱通道是同门机型中独有的（[wfview 2.20 release](https://forum.wfview.org/t/wfview-version-2-20-released/4736)）。后继机 FTX-1 的 CAT 手册结构与 FT-710 完全相同（CAT-1/3 38400、CAT-2 4800），可视为同族延续（[FTX-1 CAT OM](https://www.yaesu.com/Files/4CB1CAF6-1018-01AF-FABABCA11697FC7F/FTX-1_CAT_OM_ENG_2507-B.pdf)）。
- **与 IC-7300（CI-V）的差异**：IC-7300 用 Icom 二进制 CI-V（`FE FE` 前缀 + 地址 `94h` + `FD` 结尾），USB 波特率 115200，需设置 "CI-V USB Port = Unlink from Remote"、Echo Back 等（[aaronrombaut.com IC-7300 数字模式设置](https://www.aaronrombaut.com/icom-ic-7300-connectors-settings-for-digital-modes/)、[N1MM Supported Radios](https://n1mmwp.hamdocs.com/manual-supported/supported-radios/)）。N1MM 文档还点名 IC-7300 因**没有按 VFO 区分的轮询命令**而不能做 SO2V——FT-710 的 ASCII CAT 有 `FA`/`FB` 两条独立频率命令，无此限制。

## 3. SCU-LAN10：官方网络远程盒子

- **是什么**：以太网 LAN 单元，用附带线缆接 FT-710 **背面 USB 口**（不是 ACC 口），再由 SAD-25B 电源适配器或 E-DC-6 线供电（DC 9–16 V，≥800 mA）。远端 PC 必须装 **Windows 10/11 专用软件**（SCU-LAN10_Software_V0300），鼠标 PTT + 双频段瀑布图大屏操作。带宽建议：SCU-LAN10→PC 实效 ≥2 Mbps，PC→SCU-LAN10 ≥1.2 Mbps。([Yaesu 日本官方 SCU-LAN10 下载页](https://www.yaesu.com/jp/amateur_index/product/ft-710/download_scu-lan10.html))
- **传输内容**：四路数据走 **UDP 50000–50003**（电台控制、CAT、音频、频谱），互联网远程需在路由器做这四口的 UDP 端口转发（[RadioReference 论坛](http://forums.radioreference.com/threads/scu-lan10.472106/)）；哈罗 CQ 论坛用户实测总结同样指出"四种数据、四个 UDP 端口，频谱是这盒子的亮点"（[hellocq.net 帖子](https://www.hellocq.net/forum/read.php?tid=373943)）。wfview 开发者也观察到官方软件对 LAN 单元开 4 个不同端口的独立连接（[wfview 论坛](https://forum.wfview.org/t/off-topic-yaesu-ft710-and-others/3275?page=2)）。
- **FT-710 支持史（重要时间线）**：FT-710 上市初期 SCU-LAN10 **不支持**它（2023-10 Reddit 热帖标题即 "FT-710 does NOT support the SCU-LAN10"，[链接](https://www.reddit.com/r/HamRadio/comments/1744lnk/yaesu_ft710_does_not_support_the_sculan10_remote/)，正文抓取失败但搜索摘要明确）；2023-11-01 的 **MAIN V01-11** 固件 + SCU-LAN10 侧 **Firmware_update_202310（V3.00）+ Software_V0300** 同时更新后才可用，Yaesu 官方 PDF 强调 "**FT-710 用户必须两者都更新，否则 SCU-LAN10 无法工作**"（[SCU-LAN10 Firmware Update Information PDF](https://yaesu.com/Files/BB2B47AE-1018-01AF-FAE48FDCB1919193/Network%20Remote%20Control%20System%20SCU-LAN10_Firmware_Software%20Update%20Information.pdf)）。
- **固件时间线**（Yaesu 日本官方 + hamlife.jp）：V01-09（2023-03-29）→ V01-11（2023-11-01，加 SCU-LAN10 兼容）→ **V01-12（2024-02-29，现行最新）**，V01-12 修复的正是两条远程相关 bug："RTTY 监听音问题" 和 "**SCU-LAN 连接时发射音频出现回声**"；配套 DISPLAY V01-08、DSP V01-01、SDR V01-04（[Yaesu JP 固件页](https://www.yaesu.com/jp/amateur_index/product/ft-710/firmware.html)、[hamlife.jp](https://www.hamlife.jp/2023-03-29/yaesu-ft710-newfirm-3/)、[SM2YER 镜像的官方 PDF](http://www.popular-hifi.com/shack/hf_ft710/FT-710_Firmware_Update_Information_2-29-24-1.pdf)）。
- **价格**：HRO/GigaParts 实售 **$299.95**，eHam 标注 MSRP **$339.00**，英国 ML&S 特价 **£229.99**（原价 £299.95）（[HRO](https://www.hamradio.com/detail.cfm?pid=H0-017192)、[eHam](https://www.eham.net/reviews/view-product/14808)、[ML&S](https://www.hamradio.co.uk/yaesu-scu-lan10-network-remote-control-system-pd-11342)）。
- **大坑：FT8/数据模式官方不支持**。FTDX-10 用户组里有明确讨论："Yaesu 官方不支持在 SCU-LAN10 上用 FT8 模式"，用户只能靠虚拟声卡转发到 JTDX（RX 可行、TX 困难）或在电台侧另接一台电脑（[groups.io ftdx-10 帖](https://groups.io/g/ftdx-10/topic/any_way_to_work_ft8_remotely/96823814)）。官方软件也是 **Windows-only**（[wfview 论坛](https://forum.wfview.org/t/off-topic-yaesu-ft710-and-others/3275)）。

## 4. WFView（第三方开源频谱软件，注意不是 Yaesu 官方）

先纠正一个常见误解：**wfview 不是 Yaesu 官方软件**（官方是 "SCU-LAN10 Network Remote Control Software"）；wfview 是 W6EL/ M0VSE 等维护的开源项目，最初为 Icom 设计。FT-710 相关现状：

- **v2.20（2026-02-01 发布）首次加入 Yaesu 支持：FT-710 与 FTX-1**；FT-710 同时支持 **USB 直连**和**经 SCU-LAN10 的网络连接**；官方宣布"计划加入 Yaesu 兼容 server（届时无需 SCU-LAN10 即可远程连接）"；v2.21 修复 Windows 缺 `ftd2xx.dll` 的问题——该 DLL 只用于 Yaesu scope 数据，动态加载（[wfview 2.20 公告](https://forum.wfview.org/t/wfview-version-2-20-released/4736)）。
- **USB 直连原理与本站博客一致**：需在电台菜单里把 "SCU-LAN10" 项**打开**（无需真的有硬件）才会输出频谱；PC 端装 Yaesu USB 驱动（CP210x）+ FTDI D2XX 驱动；Linux 下 udev 规则放行 `0403:601c`，CAT 用 CP2105 的 `if00` 口，38400 bps，PTT 走 CAT 命令（[wfview FT-710 Setup 手册页](https://wfview.org/wfview-user-manual/yaesu-ft-710-setup/)）。
- **仍是 beta/实验性**：手册页明写 "FT-710 support is beta at this time"；论坛 bug 帖（v2.22 无瀑布图）中开发者回复 "FT-710 支持仍非常实验性，D2XX 驱动是商业授权需手动安装"（[2.22 No Waterfall on FT-710](https://forum.wfview.org/t/2-22-no-waterfall-on-ft-710/4958)）。
- **wfview 内置 rigctld 兼容 server**：可让 WSJT-X/fldigi 等经 `127.0.0.1:4532`（Hamlib NET rigctld）控制电台，支持多程序同时请求控制；client/server 远程架构用 **50001–50003** 端口（与 SCU-LAN10 端口段部分重叠，注意别撞）；对 USB 直连机型，**wfview 不经手音频**——数字软件直接用电台 USB CODEC（[wfview 论坛：Hamlib rigctld emulation](https://forum.wfview.org/t/hamlib-rigctld-emulation-and-audio-configuration/2694)）。

## 5. Hamlib / rigctld

- **型号与 ID**：`1049 Yaesu FT-710`，**Hamlib 4.5（2022-10-30）首次加入**（[Hamlib Download wiki changelog](https://github.com/Hamlib/Hamlib/wiki/Download)、[Supported Radios wiki](https://github.com/Hamlib/Hamlib/wiki/Supported-Radios)）。后端并入 Yaesu 通用的 **newcat.c**（changelog 可见 "FT-710: Fix FT-710 VFO swap after cross-band tune. newcat.c…"）。实用命令：`rigctld -m 1049 -r /dev/ttyUSB1 -s 38400 --vfo`（[turbidplaque.com 实测博客](https://turbidplaque.com/wp/2025-10-21/winlink-and-vara-on-linux-surprisingly-straightforward/)）。WSJT-X 中 rig 名即 "Yaesu FT-710"。
- **已知缺陷（截至 2026-03）**：
  - **通带/带宽设置失效**：`set_mode USB 2700` 在 4.6.5 与 4.7.0 上均无效（[Issue #2021](https://github.com/Hamlib/Hamlib/issues/2021)、[Discussion #2020](https://github.com/Hamlib/Hamlib/discussions/2020)，报告者用 WSJT-X/CQRlog 均复现）。
  - `IF;` 命令读取错误（[Issue #1550](https://github.com/Hamlib/Hamlib/issues/1550)，2024-05）。
  - POTACAT 文档直言：**Hamlib 路径下 FT-710 的电源开关和多个控制钮不可靠**，建议改用原生 Serial CAT（[POTACAT FT-710 文档](https://docs.potacat.com/nested/rig-ft-710.html)）；本站博客同样选择绕开 Hamlib 直写 CAT。
- **历史注脚**：2023-02 时 FLRig 和 HRD 都还没收录 FT-710，JS8Call 用户 M0IAX 用 **FTDX10 profile** 顶着用（选 DATA-U + Preset 即可）（[m0iax.com](https://m0iax.com/2023-02-05/js8call-with-yaesu-ft-710/)）。

## 7. WSJT-X / JS8Call 集成要点与坑

- **标准配置**：Rig = Yaesu FT-710，CAT 口（Enhanced COM）38400，PTT Method = CAT，音频 Input/Output 都选 FT-710 的 USB Audio CODEC，模式 DATA-U + PRESET（[autoft8.com 分步指南](https://autoft8.com/yaesu-ft-710-wsjtx-ft8-setup/)、[m0iax.com](https://m0iax.com/2023-02-05/js8call-with-yaesu-ft-710/)）。无需外置声卡接口。
- **坑清单（多为实测来源）**：
  1. **Windows 声卡采样率必须手动设为 16 bit / 44100 Hz**——Windows 默认 48000 Hz 会弄坏 FT-710 的 TX 音频（[POTACAT 文档](https://docs.potacat.com/nested/rig-ft-710.html)）。
  2. **CAT-1 TIME OUT TIMER 出厂 10 ms 太短**，会造成 `?;` 命令误拒绝，建议改 1000 ms（同上）。
  3. **MOD SOURCE 必须设 AUTO**，否则远程 PTT 能键控但无调制输出（同上）。
  4. DATA 调制源要选 USB、必要时手动 DATA-U/L；Reddit 上"WSJT-X 音频断续"帖的主因即此处（[Reddit](https://www.reddit.com/r/amateurradio/comments/1prjk1x/ft710_intermittent_stuttering_audio_on_wsjtx_no/)）。
  5. **CW 远程键控**：CAT 的 `KY` 命令不可靠（载波起来但码元素丢失），POTACAT 改走 CAT-2 口的 DTR 逐元素键控（电台菜单 USB KEYING (CW)=DTR，CW BK-IN=ON/SEMI）；Linux 上部分 `cdc_acm` 驱动控不了 DTR，会导致**电台持续发射**——卡住时把 USB KEYING (CW) 设 OFF（[POTACAT 文档](https://docs.potacat.com/nested/rig-ft-710.html)）。
  6. **ATU 无法经 CAT 远程触发调谐**——Yaesu 固件没给这条命令，只能按面板 TUNE（同上）。

## 9. Field 版 vs AESS 版（远程控制视角）

两版**主机电气/固件完全相同**，差异只在附件：AESS 版附 SP-40 外扬声器（与机内扬声器组成 AESS 系统），Field 版附背带/提手（[johnsonfrancis.org 对比](https://johnsonfrancis.org/techworld/what-are-the-differences-between-ft-710-aess-and-ft-710-field/)、[groups.io 讨论](https://groups.io/g/ftdx-10/topic/ft710_vs_ft710aess/111133606)、Yaesu JP 固件页对两版列同一固件包）。**远程控制的唯一分叉**：HRD 提到的 3 条 FT-710 新增 CAT 命令是 AESS 功能命令——Field 版没有 SP-40/AESS 硬件，这些命令无意义（[HRD](https://support.hamradiodeluxe.com/support/solutions/articles/51000337439-support-for-yaesu-ft-710)）。CAT/USB/频谱/远程能力两版一致。
