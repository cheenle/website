# 调研原始记录：IC-R9000 硬核深度改造案例

> 调研任务：调研全球玩家对 IC-R9000 的深度硬件改造实例：本振/合成器相位噪声改进、roofing filter 升级、前端改进、VCO 改进、DDS 修复、逻辑/显示替换、散热重做、软件定义化讨论；含 IC-781（同平台）改造的可移植性。
>
> 执行：并行调研代理（agent-30），2026-09-27；覆盖英文/意大利文/日文/中文 20+ 来源。

---

## 一、总体结论（先说重要的）

- **全球范围内没有找到任何公开发表的"改进 IC-R9000 本振/合成器相位噪声"或"替换一中频 20 kHz MCF roofing filter"的成型案例**。玩家的硬核改造几乎全部集中在五个方向：散热重做、电容全换（recap）、CRT→LCD/逻辑显示替换、中频输出外接 SDR/解码器（"准 SDR 化"）、以及荷兰政府监听机构的 AGC/中频通道专业改造。
- 同平台 **IC-781 的改造生态远比 R9000 深**（Inrad roofing filter 套件、PLL/DDS 板修复、整流单元重做等），其中思路可移植，但元件级方案不可直接搬用（一中频频率不同，见下）。

## 二、散热重做（最成熟、案例最多的深度改造）

R9000 无风扇、内部极热是共识，多个独立来源互相印证：

- **Sherwood Engineering 曾出售官方级 "R9000 Cooling Kit"**：替换整个后面板、加装风扇，套件 $149、代装 $65（2006 年报价，现已停售）：http://www.sherweng.com/r9000ck.html
- **YO9FZS 的 IC-781/IC-R9000 维护长文**（最权威的双平台技术文档）：REG 电源板密封无风道，"像被盖住的 3CX800"，R32/Q7 区域 PCB 烧糊是常态；建议换 105°C 电容、Q7 用 TIP132 达林顿（70W/8A）替换 2SD1406、加 3.15A 保险丝，并**安装 Sherwood 风扇套件或自制温控 3 英寸风扇（用两个 82 温度开关）**：http://www.radiomanual.info/schemi/ICOM_HF/IC-781_technical_and_maintenance_issues.pdf
- **RadioReference 实测帖（2024）**：用户在散热器正中央外挂 120mm 三速机箱风扇最低速运行，从后面板 12VDC 插座取电，"关机后还能抽出约 10 分钟温热空气"；多年免维护运行：http://forums.radioreference.com/threads/icom-ic-r9000-rear-sherwood-fan.479415/
- groups.io 上也有人**在外置散热片上加小风扇改善稳压调整管散热**：https://groups.io/g/ICOM-ICR-9000/topic/120_240_voltage/104494140
- 有趣的旁证：**晚期生产的 R9000 出厂已内置 PSU 小风扇**（约 2000 年产的机器"电源部分有个几乎无声的小风扇"）：http://forums.radioreference.com/threads/icom-ic-r9000.457423/
- KD5OEI 直言 "These receivers run very hot inside. Icom should have added a fan. You should add a fan!"：https://bunkerofdoom.com/r9000/index.html

## 三、电容全换（Recap）与大修

- **商品化套件已存在**：Klondike Mike's 出售 IC-R9000/9000L 电解电容全套件，**共 197 只（含双极性电容），全部为 Rubycon/Nichicon/Panasonic 一线品牌，耐压 25V 起步**；也可单买电源部分 20 只：https://klondikemikescapkits.com/products/icom-ic-r9000-9000l-electrolytic-capacitor-kit
- groups.io "R-9000 overhaul completed"（2022）：**全部年限电容更换 + 整机重调**完成：https://groups.io/g/ICOM-ICR-9000/topic/r_9000_overhaul_completed/89926848
- 注意反对意见：RadioReference 群组管理员（自新机持有 R9000）认为**整机 recap"有点冒险"，建议修而非全换**（容易引发新故障），他自己只 recap 了电源：http://forums.radioreference.com/threads/icom-ic-r9000.457423/
- 典型热致失效点：CRTC 视频板 **C11**（多层屏蔽盒夹心位置，烘干后丢垂直同步 → 画面乱）；KD5OEI 经典修复文：https://bunkerofdoom.com/r9000/index.html ；中文 hellocq 网友按此文同样换 C11 修好：https://www.hellocq.net/forum/read.php?tid=353933
- Icom 美国官方 FAQ：稳压单元 DC-DC 变换段电解老化导致 -12V/-7V 跌落 → 静噪异常/S 表不归零；稳压噪声还会**失谐前端变容管**造成 VHF/UHF 全段灵敏度下降：https://www.qsl.net/icom/oldicomfaq/ic-r9000.html
- EEVblog 有 R9000 电源单元维修帖（C5/C6 完全干涸、热击穿）：https://www.eevblog.com/forum/repair/icom-ic-r9000-power-unit/
- 同平台 IC-781 官方维修 FAQ 亦要求"**把所有受热变棕色的蓝色电解全部换掉**"：https://www.qsl.net/icom/oldicomfaq/ic-781.html

## 四、CRT→LCD 与逻辑/显示控制替换

- **日本 TBHD 公司把 IC-R9000/IC-780 的 CRT→LCD 列为正式收费改装包**（有 2024-09 施工视频）：https://tbhd.jp/ 、https://www.youtube.com/watch?v=7f77cUkDOoo
- **日本玩家 DIY 案例（糸車のたぬき）**：用市售 5 英寸车载 LCD（兼容复合 CVBS 与 NTSC），LCD 实测 12V 下仅约 160 mA，直接从 CRT 单元 6P 电源连接器取电；CRT 单元单体 1740 g，拆后减重明显；**坚持可逆原则**：http://www.seidensha-ltd.co.jp/~seiden/ic-r9000.html
- **商品化替换件**：eBay 在售 "ICOM IC-781 IC-R9000 LCD Module replacement part"：https://www.ebay.com/itm/116614426725 ；groups.io 有专帖讨论该 eBay LCD 在 R9000 上的适配：https://groups.io/g/ICOM-ICR-9000/topic/ic_r9000_lcd_replacement/83837805
- IZ0FIB（意大利）收集了 **UX-R9000 LCD 单元替换 CRT 的安装文档**：https://iz0fib.jimdofree.com/info-e-modifiche-su-radio-e-accessori/icom/ic781/
- **逻辑部分修复**：groups.io "R-9000 data error" 帖——存储 SRAM 可直接换通用 32k×8 SRAM（注意 VDR 数据保持电压参数）：https://groups.io/g/ICOM-ICR-9000/topic/r_9000_data_error/104134716 ；Icom FAQ 记载逻辑错乱/地址故障用 SW-D 单元 J7 插 W1 跳线 + CPU 复位解决：https://www.qsl.net/icom/oldicomfaq/ic-r9000.html
- 另类玩法：CRT 烧屏严重时**把 CRT 旋转 180° 并反接偏转线圈**作临时改善（groups.io 主题列表）：https://groups.io/g/ICOM-ICR-9000/topics

## 五、本振/合成器/VCO/DDS——只有维修，没有改进案例

- Icom 官方 FAQ 揭示了合成器薄弱环节：PLL B 单元的 **768 Hz VCO（IC15）温度敏感**，热机后在 30–499 MHz 与 1000–1499 MHz 段 FM 出现呜声/噪杂；500–999/1000–1499 MHz 段问题查 **268 MHz VCO**；全段无接收且绿灯灭 = PLL 失锁，从参考源→DDS→HPL 逐级排查：https://www.qsl.net/icom/oldicomfaq/ic-r9000.html
- **IC-781 侧 2024 年有新文章 "ICOM IC-781 PLL / DDS board 'A' FIX"**（mods.dk，2024-05-20），IC-781 groups.io 也有 PLL/DDS A 板重新调整教程——781 与 R9000 同为 DDS+PLL 架构，修复/重调方法可移植：https://www.mods.dk/index.php?ModelId=299
- **未发现**任何玩家公开发表用现代低相噪 PLL/DDS（如 ADF4351、LMX 系列）重做 R9000 本振的案例。原因可推断：R9000 主合成器要覆盖到 2 GHz 本振且与四变频矩阵、CI-V 深度耦合，重做成本远超收益。

## 六、Roofing filter（一中频 MCF）——无 R9000 案例，IC-781 方案概念可移植

- **Inrad 曾量产 IC-781 roofing filter 改装套件**（已停产）：在第一混频器后的 PIN 衰减器与接地栅极一中频放大器之间插入 **6 极、4–5 kHz 宽晶体滤波器 + 高动态范围反馈放大器**（补偿插损），官方称某些间隔下 **IMD 动态范围改善 7–14 dB**，且开启噪声抑制器时动态范围劣化减小：https://www.inrad.net/product.php?productid=259
- IZ0FIB 存档了两份安装 PDF：https://iz0fib.jimdofree.com/info-e-modifiche-su-radio-e-accessori/icom/ic781/
- **可移植性关键障碍**：IC-781 是 HF 单段机、一中频 70.455 MHz 单一；R9000 的 HF 一中频在 48.8 MHz、VHF/UHF 走另一中频链，晶体滤波器须按 48.8 MHz 重新定制，且 R9000 定位是宽带扫描接收机，窄 roofing 与 230 kHz 频谱显示/宽 FM 模式存在定位冲突。Sherwood 的经典论述（6–20 kHz 宽一中频在密集信号下必然过载）见 http://www.sherweng.com/documents/barc2008.pdf ——这正好量化了 R9000 20 kHz MCF 的局限，但**无人实际动手替换过**。

## 七、前端改进

- 未见成体系的"前端增强"改造；主要是**维修性替换**。日本 JH8XVH 的 IC-780（= IC-781 日版）前端修复实录最有参考价值：灵敏度掉约 -15 dB，最终定位到第一混频器屏蔽单元内 **Q304/Q404 双栅 FET 电阻化损坏**，射频头 FET 为 2SK125（Idss 配对品易得）；他提醒"初段 FET 换了没用、祸根在混频单元内部供电管"：https://jh8xvh.hdlc.jp/radio/ic-780.html
- RigPix 列出 R9000 前端用料：30–1000 MHz 为四只 3SK121 双栅 MOSFET 滤波放大，1000–2000 MHz 为 uPC1678G MMIC：https://www.rigpix.com/icom/icr9000.htm —— 这些是寻找现代替代管（如 BF998 系列）做前端修复的入口。
- Icom FAQ 记载前端各段（30–89/90–249/250–499/500–999 MHz 分别对应 RF B 单元 Q1–Q4）遭 RF 过载烧毁后的分段排查法：https://www.qsl.net/icom/oldicomfaq/ic-r9000.html

## 八、"软件定义化"讨论与外接数字生态（最活跃的现代玩法）

没人把 R9000 内部改成 SDR，但"模拟前端 + 外接 SDR/解码器"已是成熟套路：

- **意大利 TSP 的 IFace 缓冲板方案**：从 IF 单元第二混频后取 **10.7 MHz 中频**（全频段恒定），给出原理图取样点与 PCB 实物取点照片，接 SDR 作全景显示：https://www.tspelettronica.com/en/2020/06/29/panadapter-sdr-per-ic-r9000/
- **RadioReference 实测全记录（2024–2025，最有价值）**：把 AOR **AR-DV1** 接 R9000 的 10.7 MHz IF 输出，实现 DMR/D-Star/C4FM/Tetra 硬件解码。两个关键坑：① **R9000 的 IF 输出频谱是反的**，AR-DV1 需设 IF DIR = REV（说明书正文没有，在增补手册里）；② IF 输出电平偏弱，用劣质 RCA 视频线会损耗到无法解码，**换 BNC-BNC 射频线后"set and forget"**。也可用 ARD300 或鉴频输出 + DSD+/SDR#：http://forums.radioreference.com/threads/ic-r9000-digital-modes.475682/
- 同站老帖建议：SDR 接 10.7 MHz 口可作 **230 kHz 带宽全景显示**：http://forums.radioreference.com/threads/icom-ic-r9000.457423/
- 日本 5ch 也有用户把 **AOR ARD300 数字解码器接 IC-R9000** 听数字无线：https://itest.5ch.net/lavender/test/read.cgi/radio/1742897295
- groups.io Icom-ICR9000 群持续讨论 "SDR dongle 作 panadapter + CI-V 联动" 与 "CI-V 接口替代方案"：https://groups.io/g/Icom-ICR9000/messages?expanded=1 （注：groups.io 有 JS 反爬，只读到检索摘要）
- 模式级微调讨论：手动选 FM-W 30 kHz 而非 WFM 150 kHz，DX 时可有 **14 dB S/N 改善**（groups.io 摘要）：https://groups.io/g/ICOM-ICR-9000/messages?page=19&subsort=1

## 九、最深度的"官方级"改造：荷兰监听局 RCD/AT 的 PAN-2000 配套改造

Crypto Museum 详录（含电路图 PDF），约 20 套系统，2005–2007 退役后流出：

- **改 AGC 电路、换用另一条 10.7 MHz 中频通路、改变若干滤波器特性**以配合 PAN-2000 FFT 全景截收系统；
- 废弃劣质 RCA IF 口，**新增 BNC 的 10.7 MHz IF 输出**（换特氟龙同轴线直焊 IF 单元），因原位置会拾取杂散；
- 新增 **鉴频器/中心表输出（CM OUTPUT）**：从解调板 IC14 pin1（R221 上端）经 10 kΩ 电阻串同轴引出，供 PAN-2000 精调谐；
- **切断 CRT 供电省电 1 A**（面板 DISPLAY 键只断视频不断电）、拆重型工频变压器电源减重（车载）、禁用定时开关、REMOTE 改 BNC，最后整机重调：https://www.cryptomuseum.com/df/icom/icr9000/mod.htm

这是目前文献中唯一对 R9000 的 **AGC/中频信号通路本身**做深度改造的案例，且由专业监听机构工程化实施，对"现代化改造"的方案设计（尤其是干净的 IF 取样点与 AGC 时间常数）最具参考价值。

## 十、补齐短板的周边改造：同步检波

R9000 无同步检波。**Sherwood SE-3 Mk IV 锁相 AM 乘积检波器**官方支持 R9000 与 IC-781：SE-3 需要 455 kHz、30 mV–2 V RMS 的中频输入，R9000/IC-781 属"需要变频器（MIX-2/MIX-3）+缓冲板"一类，Sherwood 提供改装服务；对收音/ECSS 场景响应 30 Hz–15 kHz：http://www.sherweng.com/indepth.html

## 十一、对"提升到现代旗舰水平"方案的含义

1. **散热与 recap 是收益/风险比最高的改造**，有商品化套件（197 件电容套件、历史上的 Sherwood 风扇面板）和大量成功先例；注意 RadioReference 群组对"盲换全机电容"的警告。
2. **相噪/roofing 是没人趟过的空白**——若要做，IC-781 的 Inrad 方案（窄晶体滤波器 + 高动态补偿放大器插在第一混频后）是唯一可参考的工程模板，但须按 48.8 MHz 重定制并解决与宽频谱显示的模式冲突。
3. **现代化最现实的路径是"外挂"**：10.7 MHz IF → SDR 全景/DSP 解调（注意频谱反转与电平）、AR-DV1/ARD300 硬件解码、SE-3 同步检波、CI-V 联动——这些已有可复制的实证。
4. 荷兰 RCD 改造证明：在不动合成器的前提下，重做 AGC 特性与 IF 取样通路是被专业机构验证过的"半深度"路线。
