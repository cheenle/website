工程实践

Fuchs ATU V3.0 — 伺服驱动精密调谐

第三代自动调谐器以连续伺服调谐替代继电器组，将 SWR 检测委托给 MRRC/ATR1000，并添加 WiFi 实现全远程控制——同时将故障点从 9 个减少到 2 个。

连续伺服调谐

ESP32-S3 LEDC PWM 驱动 MG996R 伺服电机，50Hz。空气可变电容（10–500pF）提供精确、连续的电容调节——无离散继电器档位，无死区。

  • 两阶段扫描：37 粗步（5°）+ 30 精步（1°）
  • 已知频率缓存命中 <1 秒
  • 全扫描最坏情况 <10 秒

ESP32-S3 核心

240MHz 双核 Xtensa LX7，16MB 闪存。五个 FreeRTOS 任务并行协调调谐、WiFi 通信、健康监控、NVS 持久化和伺服控制。

  • ESP-IDF v5.x C 固件，约 2800 行
  • 5 个 FreeRTOS 任务 + cJSON 协议解析
  • NVS 学习缓存：频率 → 伺服位置映射

偏压器同轴供电

13.8V DC 与 RF 和控制数据在同一根同轴电缆上传输。室外单元无需单独电源线——单根 RG-58 或同等同轴电缆即可完成全部工作。

  • 室内偏压器单元将 DC 注入同轴电缆
  • 室外 IP66 铝制外壳
  • 单根同轴：RF + DC 供电 + WiFi 数据

安全系统

多层保护：120W 阈值过功率中断、通过远程 ATR1000 检测的高 SWR 保护、2.2MΩ ESD 泄放电阻、带看门狗定时器的持续健康监控。

  • 过功率检测与中断（>120W 阈值）
  • 高 SWR 自动中断 + ATR1000 反馈回路
  • 2.2MΩ ESD 泄放 + 看门狗健康监控

Fuchs LC 耦合器

成熟的并联 LC 谐振电路设计。T200-6 6 型羰基铁粉磁环（μ=8），2:14 匝比实现 49:1 阻抗变换。连续电容替代固定/切换电容组。

  • T200-6 磁环 — μ=8 羰基铁，低损耗
  • 2:14 匝比 → 49:1 阻抗比
  • 10–500pF 空气可变电容，伺服驱动

MRRC 生态集成

WebSocket 协议直接连接 MRRC 服务器。SWR 测量委托给 ATR1000 以实现精确检测。MRRC Web UI 提供完整 ATU 控制面板——手动调谐、频段扫描、缓存管理。

  • WiFi 2.4GHz WebSocket 连接 MRRC 服务器
  • ATR1000 SWR 检测 — 无板载 SWR 电桥
  • MRRC Web UI ATU 控制面板

按 BOM 表订购零件——全部可在淘宝/JLC 购买。总成本约 ¥430。

烧录固件

克隆仓库，配置 WiFi 凭证，使用 ESP-IDF v5.x 构建并烧录。

git clone https://github.com/cheenle/efhw-knowledge && cd auto-efhw-tuner/firmware-esp32 && idf.py build flash

连接与配置

将电台偏压器的同轴电缆连接到 ATU。ATU 加入您的 WiFi 并向 MRRC 注册。

单根同轴：偏压器（室内）→ RG-58 → ATU（室外）→ EFHW 天线导线
