# ICOM IC-R9000 深度研究报告

> 调研时间：2026-09。来源覆盖 RigPix、Crypto Museum、Radio Netherlands/MWC 评测、Sherwood Engineering、Icom 官方服务 FAQ、eHam/QRZ/RadioReference 社区、日本修理圈与拍卖数据、YouTube/Bilibili 视频档案，以及本地存档 `../ic-r9000.html`（JA4FUQ 使用报告）。

## 一、定位与历史

- ICOM 1989 年推出的旗舰宽频接收机，**100 kHz – 1999.8 MHz** 连续覆盖，全模式（AM/FM/WFM/SSB/CW/FSK，还能解调模拟电视画面）。定位是"业余价格、专业性能"：当年 Rohde & Schwarz / Watkins-Johnson / Anritsu 专业监听机要 200 万日元以上，它卖 **598,000 日元**（美国 $4,700–4,795，英国 £4,080）。
- 与同期旗舰发射机 **IC-781** 共用机箱与 5 英寸琥珀色 CRT 频谱显示设计，但并非"去掉功放的 781"。
- 生产期 **1989–1998（CRT 版）**；1999 年起改为 **IC-R9000L**（TFT 液晶，其余规格几乎一致）至 2006 年，之后由 3 GHz 的 IC-R9500 接替。日本当年定价、施网渔船搭载实绩均有记载。
- 美国因蜂窝监听法规，后期仅限政府机构购买。荷兰无线电监测局曾将其用于 **PAN-2000 移动截听系统**（拆市电变压器减重、关 AGC、加 10.7 MHz IF/鉴频 BNC 输出等大量改造），退役机 2005–2007 流入民间。

## 二、核心规格

| 项目 | 参数 |
|---|---|
| 频率范围 | 0.1–1999.8 MHz（法国版剔除 87.5–108 MHz；德国版大砍频段；澳大利亚版 2 MHz 起） |
| 灵敏度 | SSB/CW 1.8–30 MHz：**0.16 µV**（10 dB S/N）；30–1000 MHz 0.32 µV；1600–2000 MHz 1.0 µV |
| 选择性(-6dB) | SSB/CW 2.4 kHz / AM 6 kHz / FM 15 kHz / WFM 150 kHz |
| 频率稳定度 | HF ±25 Hz；30 MHz 以上 ±0.25 ppm |
| 存储 | 900 频道 + 100 自动写入 + 10 优先，8 字符标签 |
| 频谱仪 | CRT，±25/±50/±100 kHz 扫宽，扫描时仍工作；可作 RTTY ASCII 终端 |
| 抗干扰 | 10/20/30 dB 衰减、IF Shift、50 dB Notch、宽窄 NB、AFC |
| 体积重量 | 424×150×365 mm，**20 kg** |
| 天线口 | HF：SO-239 + RCA；30–1000 MHz 与 1–2 GHz 各一个 N 座 |

## 三、电路架构

- **四次变频超外差 + IF 矩阵**：1st IF 分段（HF 用 48.8 MHz，30–500 MHz 用 778.6 MHz，500–1000 MHz 用 278.6 MHz），2nd 10.7 MHz → 3rd 455 kHz → 4th 10.7 MHz；**1 GHz 以上用下变频单元**。
- 前端：30–1000 MHz 段四只 **3SK121 双栅 MOSFET**（JA 资料记 2SK125×2 栅地放大 + 推挽 SBM 混频），1–2 GHz 用 uPC1678G MMIC；前端为二极管切换 11 段 LPF/BPF 预选器 + PIN 衰减器。
- **全模拟设计**（1989 年早于 IF-DSP），滤波全为晶体/机械滤波器；DDS 本振 + ±0.25 ppm TCXO。
- 455 kHz 级滤波器（JA4FUQ 底盖实拍确认）：FL-44A（±1.2 kHz）、FL-52A（±250 Hz）、CFW455B/E/HT、CFJ455K5 等。

## 四、实测性能（专业评测）

- **Radio Netherlands / MWC**（Jonathan Marks 等）：合成器本底噪声极低；窄 SSB 滤波器下实测**动态范围 102 dB**；无同步检波；键盘小而密被批评；内部杂散点：574 kHz 较强，11670/11755/18543/27815 kHz 弱杂散。结论："只听 30 MHz 以下难以值回票价，加上 VHF/UHF 则物有所值"。
- **Sherwood 实测**：底噪 -131 dBm、灵敏度 0.15 µV、本振噪声 128 dBc/Hz@10kHz、阻塞 129 dB@100kHz；**宽间隔 DR 93 dB@20kHz，窄间隔（5 kHz）71 dB** —— 受 0.5 倍频程前端滤波器限制，但在同代四机（NRD-535 70 / FRG-100 65 / R-5000 65）中居首。
- Passport/RDI 曾出版专题白皮书（已绝版）。

## 五、通病与维修（重点）

**根因：散热差**。"盒子套盒子"结构 + 线性电源，整机长期高温，几乎所有老化问题由此而来。

1. **电解电容批量干涸**（最著名，绰号"电容烧烤炉"，有人一次换 90 颗）
   - DC-DC 变换器（屏蔽盒内）电容老化 → -12V/-7V 负压异常 → 静噪紊乱、音量/静噪旋钮互相干扰、灵敏度下降、S 表不回零
   - REG 电源单元电容失效 → V/UHF 前端变容二极管失谐 → 全频段尤其频段边缘灵敏度下降
   - 对策：预防性全换 105°C 高品质电容；eBay 有整机/REG 单元专用套件
2. **CRT 显示系统**（早期版最大软肋）
   - 烧屏（几乎每台都有）、变暗/聚焦劣化；CRTC 板 **C11** 干涸 → 画面崩溃（KD5OEI 经典案例）；CRT 监视器板 **C407/C410** → 垂直线性差
   - **官方维修已全面终止**（连 R9000L 的 LCD 也不再供应）
   - 出路：第三方 LCD 改装（eBay 模块约 $136；阿里巴巴 VS Displays 套件；JA4FUQ 的可逆 DIY 方案见本地存档）；或外接 NTSC 监视器
3. **VCO/PLL**：768 Hz VCO 温敏（热机后 FM 啸叫，换 PLL B 单元 IC15）；同时代 Icom 通病——**村田塑料壳微调电容**劣化，中招维修费很高
4. **记忆电池**：两颗电池（时钟 + RAM 备份，BR2032 带焊片），寿命 5–7 年；**必须并接外部 3V 不断电更换**，否则 RAM 丢失需返厂
5. **VFO 光学编码器**：润滑脂干涸卡滞，需解体清洗重润滑；含步进开关，薄开槽盘片易损伤
6. **其他**：N 座中心针被 PL-259 撑开（30 MHz 以上灵敏度骤降）；CRT 板/VR-C 板焊点热循环开裂（重焊即可）；外壳易崩漆

**预防性维护三板斧**：加风扇（Sherwood 冷却套件 $149 或 DIY 12cm 风扇接后背 12V 受控插座）→ REG/DC-DC 预防性换电容 → 趁电池未死换记忆电池。另：市电调压到机器设计的 100/200V 档可大幅降低发热。

## 六、二手行情

- 欧美：2021–2022 年约 $1,000–2,200（CRT 校正过 €999–1,860）；成色好 $2,200–4,000；R9000L 约 $3.5–3.8K
- 日本雅虎拍卖（180 天成交）：**平均约 52,254 日元**，区间 65,000–198,122 日元（含元箱/厂家 LCD 化履历者接近 20 万）；2000 年代均价曾达 22.5 万日元
- **风险提示**：大量机器曾被政府机构 24/7 使用，CRT 烧蚀和老化严重，优先选轻度使用的个人机

## 八、JA4FUQ（本地存档）改造报告要点

见 `../ic-r9000.html`：购入海外 5 寸 LCD 套件（VGA 板+LCD，支持 NTSC 输入），实测机内视频为 NTSC、LCD 仅耗 160 mA，直接取原 CRT 单元 6P 电源；**完全可逆**（不钻孔、用原螺孔和胶粘），减重约 1.5 kg。关键警示：**CRT 单元官方已停止维修，R9000L 同样**——CRT 一旦完蛋只能走第三方 LCD 或外接监视器。
