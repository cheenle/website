# 调研原始记录：IC-R9000 与 SDR 结合

> 调研任务：调研把 IC-R9000 与 SDR 结合的实践——10.7 MHz 中频引出做频谱瀑布、IF tap 缓冲、HDSDR/SDRSharp/SDRConsole、CI-V 联动（OmniRig）、外接 SDR 替代内置 CRT 频谱仪、L 波段卫星玩法。
>
> 执行：并行调研代理（agent-29），2026-09-27；15+ 来源。

---

## 一、核心事实：R9000 的 10.7 MHz IF 引出有两条路，特性完全不同

**1. 背板原厂 IF OUT（RCA/CINCH 插座）——免开刀，但带宽受限于所选滤波器**

- R9000 背板自带 10.7 MHz IF 输出。RadioReference 实测帖指出：该输出口**信号电平跟随天线输入**（AGC 动作时会变化），且**位于中频滤波器之后**——若用 WFM 的 230 kHz 宽滤波器，瀑布图最多看 230 kHz 宽；用窄滤波器则更窄。发帖人的目标正是"用 10.7 MHz tap 驱动 SDR 在大屏显示瀑布 + 录制 230 kHz 一段基带事后解码"（[RadioReference: Panadaptor with waterfall for Icom R-9000](https://forums.radioreference.com/threads/panadaptor-with-waterfall-for-icom-r-9000.468000/)）。
- 关键坑：**R9000 的 IF OUT 频谱是镜像反转的**。意大利用户把 AOR AR-DV1 接 10.7 MHz IF OUT 做数字模式解码（DMR/Tetra 等），必须在 AR-DV1 菜单里把 "IF DIR" 从 NOR 改为 REV（F→9 OPTION→IF DIR→REV→ENT），且该功能只在增补手册里有；改完即"set and forget"，调谐全在 R9000 上进行。另一教训：用户最初用老式 RCA 视频线连接导致 10.7 MHz 处损耗大、信号偏弱，换 BNC-BNC 射频线后正常。另有提醒：某些 Icom 的 IF 口可能带直流（R8500 曾如此），接外部设备前需确认、必要时加 DC-block（[RadioReference: IC-R9000 & digital modes](http://forums.radioreference.com/threads/ic-r9000-digital-modes.475682/)）。

**2. 机内 IF tap（第二混频器输出）——宽频谱，需加装缓冲板**

- 意大利 TSP Electronics 有针对 R9000 的完整改装文档：因 R9000 各波段一中频不同（HF 段 48.8 MHz 等），唯有**第二混频器之后的 10.7 MHz 对所有频段恒定**，故 panadapter 取点选在 RX 链第二混频器输出、10.7 MHz 滤波器之前；文中给出 IF UNIT 原理图取点、PCB 实物取点和缓冲板取电点照片。其 IFace 缓冲板为宽带缓冲，输出 50 Ω 给外部 SDR；接收机无需 PTT 信号（[TSP: IC-R9000 with SDR panadapter](https://www.tspelettronica.com/en/2020/06/29/panadapter-sdr-per-ic-r9000/)，另见 [TSP 的 HDSDR+CAT 配置文](https://www.tspelettronica.com/en/2020/01/17/impostazioni-hdsdr-per-panadapter-sdr-e-cat/)："在第一混频器后、roofing filter 前取样……缓冲板复制信号而不加载混频电路"，配 SDRplay RSP1 + HDSDR + OmniRig）。
- 通用缓冲板方案：G4HUP 设计的 PAT（Panoramic Adapter Tap）板，由 SDR-Kits 继续销售。官方警告与本案直接相关：**取点在 roofing filter 之后则全景带宽被滤波器限死；取点在滤波器之前可获 200 kHz 甚至更宽的显示**，且"第二接收机"玩法必须取在滤波器之前并配合 HDSDR 特殊设置（[SDR-Kits: Panoramic Adaptor Tap Boards](https://www.sdr-kits.net/Panoramic-Adaptor-Tap-Boards)）。
- 低成本 DIY 路线：Mirko Pavleski 的老机 panadapter 方案（Hackaday 2026-02 报道）——第一中频滤波器前用 **FET 放大器做高阻取样隔离，再接射随器 + 低通滤波**做 50 Ω 匹配输出给 SDR，附 YouTube 演示视频（[Hackaday: Adding A Panadapter To A Classic Receiver](https://hackaday.com/2026/02/25/adding-a-panadapter-to-a-classic-receiver/)）。

## 二、频谱反转与软件侧处理

- R9000 IF 频谱反转这一点在各软件里都有现成对策：HDSDR 用 "Swap I and Q Channel for RX Input" / "Mirror RF Spectrum in general"（[G4ZFQ: HDSDR IF Panoramic Display](https://sites.google.com/site/g4zfqradio/hdsdr-if-pano)，该页还详述了偏置校准法：用 WWV 或 BBC 999 kHz 等已知精确频率的 AM 台读出差值填入 Offset，再逐模式校准 LSB/USB 偏移；并建议 RTL 棒子把 Global Offset 设约 50000 以避开中心杂散）。
- SDR Console（SDR-Radio）的 External Radio 功能在 Radio Definitions 里有现成的 **Invert Spectrum** 勾选项（[SDR-Radio.com: External Radio Synchronisation](https://www.sdr-radio.com/external-radio)）。

## 三、CI-V 联动控制（OmniRig 同步调谐）

- R9000 的 REMOTE 口（CI-V，3.5 mm）是联动枢纽。Crypto Museum 记载荷兰 RCD 监听部门甚至嫌 3.5 mm 不可靠，把 REMOTE 改到 BNC 座上（[Crypto Museum: IC-R9000 Modifications](https://www.cryptomuseum.com/df/icom/icr9000/mod.htm)）。
- 三种主流联动路径，均有详细文档：
  - **HDSDR + OmniRig**：HDSDR 内置 OmniRig 接口，四种同步模式，推荐 "Full sync in both directions"——点瀑布图电台跟着跳、转 R9000 旋钮瀑布跟着走；OmniRig 的 Poll int 建议降到 100 ms 提升响应（[G4ZFQ 页面](https://sites.google.com/site/g4zfqradio/hdsdr-if-pano)、[pa9x.com TS-480 教程同理](https://www.pa9x.com/how-to-setup-a-panadapter-for-the-kenwood-ts-480/)）。
  - **SDR Console External Radio**：基于 OmniRig，SDR 从电台 IF 口取信号时用 "Fixed Offset" 选项；同样建议 Poll Int ≤100 ms（[SDR-Radio.com](https://www.sdr-radio.com/external-radio)）。DXLab 用户可用 Commander 桥接（[DXLab Wiki](https://www.dxlabsuite.com/dxlabwiki/SDRConsoleCWSkimmerConfiguration)）。
  - **SDR#（SDRSharp）**：2026 年 6 月 IU4HMY 发布了专门的 SDR# Panadapter 插件，OmniRig 负责电台同步，需配置接收机 IF 频率和各模式偏移（[argio.eu: SDR# Panadapter Plugin](https://www.argio.eu/sdr-panadapter/)、[opensourcesdrlab 报道](https://blog.opensourcesdrlab.com/archives/sdr-4d04dc4ac6d04561ad)）；更早有 TAG Loomis 的 OmniRig Sync 插件（[groups.io/airspy](https://groups.io/g/airspy/topic/omnirig_sync_panadapter/34234369)）。
- OmniRig 用每机型一个 .ini 文件描述 CAT 命令集（[K9JM CI-V Router/OmniRig 文档](http://k9jm.com/CIV_Router/OmniRig.pdf)）；R9000 走标准 CI-V 协议，老 Icom 接收机 CI-V 可低至 300–1200 波特（[RadioReference 讨论](http://forums.radioreference.com/threads/icom-receiver-ci-v-to-repeater-controller-r30-baud-rate.440248/)）。注意：groups.io 的 Icom-ICR9000 小组 2025 年有专门的 #panadapter 讨论串（提到"瀑布 + 数字解码"和"让显示器接受 CI-V 显示当前频率"的想法），但页面被反爬验证挡住，只读到搜索摘要（[groups.io/g/Icom-ICR9000](https://groups.io/g/Icom-ICR9000/messages?expanded=1)）。

## 四、用外接 SDR 替代内置 CRT 频谱仪

- 历史上这就是官方玩法：荷兰 RCD 的 **PAN-2000 车载截收系统**（1995 年起约造 20 套）= R9000 + ELCOM FFT 处理器。FFT 处理器吃 R9000 的 10.7 MHz IF 输出，用 Raytheon TMC2310 硬件 FFT 芯片生成全景频谱，**最大扫宽 10 MHz**，经 TOSLINK 光纤驱大屏；为此要专门改装 R9000：换用另一路 10.7 MHz IF 通道、改 AGC、把劣质 RCA 的 IF OUT 换成 BNC + 特氟龙同轴（原厂 IF OUT 位置"会拾取杂散和噪声"）、新增鉴频器 CENTER 表输出 BNC（[Crypto Museum: PAN-2000](https://www.cryptomuseum.com/df/pan2000/index.htm)、[IC-R9000 Modifications](https://www.cryptomuseum.com/df/icom/icr9000/mod.htm)）。这套官方改装清单可直接当作今天 SDR panadapter 改装的工程参考。
- CRT 本身：R9000 的 CRT 有视频输出可外接监视器（[Medium Wave Circle 评测](https://mwcircle.org/legacy-receiver-reviews/receiver-review-icom-ic-r9000/)）；CRT 维修/替换资料见 [Bunker of DOOM](https://bunkerofdoom.com/r9000/) 和 [RadioReference Wiki: IC-R9000](https://wiki.radioreference.com/index.php/IC-R9000)。既然 IF OUT 或机内 tap 都能驱动全彩大屏瀑布，"SDR 大屏 + CRT 关屏/拆除减重"（RCD 当年关 CRT 供电省了 1 A）是完全成立的方向。

## 五、L 波段/卫星玩法

R9000 原生覆盖到 1999.8 MHz（[RigPix](https://www.rigpix.com/icom/icr9000.htm)），所以 L 波段多是"直收"，下变频器用于 10 GHz 以上：

- **QO-100/Es'hail-2（10.489 GHz 下行）**：标准 PLL LNB 把下行变频到约 **739 MHz**，正在 R9000 覆盖内。AMSAT-DL 论坛实测讨论证实用宽带接收机直收 739 MHz LNB 输出完全可行（多哈测试用 AOR AR-6600，信号强到要关增益）（[AMSAT-DL Forum](https://forum.amsat-dl.org/index.php?thread/2818-anybody-tried-receiving-739mhz-with-wideband-rx-of-ft-100-ic706-ft-897-directly/)）。AMSAT-DL 官方下变频器则把 LNB IF 转到 144 MHz（窄带转发器）/1340 MHz（宽带转发器）——两个口 R9000 都能收（[DD1US: QO-100 Es'hail-2 PDF](https://www.dd1us.de/Downloads/QO-100%20EsHail-2%202019-06-07%20rev7%20final.pdf)）。
- **GOES/Meteosat 1691 MHz WEFAX**：1.69 GHz 气象卫星下行同样在 R9000 原生覆盖内，90 年代即有整套 1691 MHz WEFAX 接收设备方案的时代文献（[Satellite Times 1996-09/10](https://www.worldradiohistory.com/Archive-Satellite-Times/Satellite-Times-1996-09-10.pdf)）；配 1.7 GHz 前置放大 + 下变频到 137 MHz 的做法见 [F1AGW 存档的 VHF.COM 文章](http://f1agw.free.fr/Catalogue/VHF_COM.pdf)。
- 联动建议：卫星下行多为 FM/数字，正好用前面 10.7 MHz IF OUT → SDR/AR-DV1 的链路做解调，R9000 充当前端 + 第一级下变频。

## 六、改造方案要点汇总

| 课题 | 推荐做法 | 依据 |
|---|---|---|
| 频谱带宽 | 机内第二混频器后、10.7 MHz 滤波器前 tap（宽显示）；背板 IF OUT 仅 230 kHz 以内 | TSP、SDR-Kits |
| 缓冲 | FET 高阻缓冲 + 射随 50 Ω 输出，或 IFace/PAT 成品板 | Hackaday、TSP、SDR-Kits |
| 接口 | 弃 RCA 换 BNC + 特氟龙线（RCD 官方改法） | Crypto Museum |
| 频谱反转 | 软件 Swap I/Q / Invert Spectrum，硬件解码器用 AR-DV1 的 IF DIR=REV | RadioReference、SDR-Radio、G4ZFQ |
| 联动 | CI-V → OmniRig（Poll ≤100 ms）→ HDSDR Full Sync / SDR Console External Radio / SDR# 插件 | G4ZFQ、SDR-Radio、argio.eu |
| 卫星 | LNB 739 MHz 直收 QO-100；1691 MHz 直收气象星；IF OUT 接 SDR 解调 | AMSAT-DL、DD1US |
