## 1. 目标与定位

在 EFHW 产品站新增接收噪声专题页。**这不是「CMC 器件页」，是「接收噪声治理页」，CMC 是其中最大的一件工具而非答案本身。**

页面的核心交付是一个**判断**：读者读完知道自己的噪声该不该花钱治、该花在哪儿、以及什么时候答案是「什么都不用买」。

### 定位理由

用户初始诉求是「增加一项 CMC 专项」。经四轮澄清扩到本形态：

1. 全站现有 CMC 内容**全是发射视角**（`mrrc/efhw/index.html` §04 讲 RFI 进家电、别扼住地网；`baluns.html` 表格里一句「这是 TV/RPI 噪声那一项」）。接收视角是真实缺口。
2. CMC 话题天然全是 dB 与 Ω，而 `check_baluns.py` 明令禁止无来源的 dB 数字。用户裁定走 **[C] 引证 + 可复算算式 + 教读者自己证明**（A+B），**不产出新的 [M] 数据**。
3. 用户随后要求扩到「环境干扰」全链路（电力线路 / 劣质开关电源 / 电动汽车充电器 / 供电 → 电磁环境 → 馈线）。这一扩把页面从「器件专题」变成「治理专题」。

### 3.1 §01 Measure first, buy later

**这是全页的诚实支点，也是与其他所有 CMC 文章的分野。**

必须先写 BG1SB 本站实测反例（来源 `efhw-knowledge/measurements/bg1sb_20m_efhw_case_study.md` §2.5/2.6）：

- 最安静方向可听到 −23 dB（FT8 解码极限约 −24 dB），接近理论灵敏度
- 各方位噪声底均匀，**无方向性噪声源**
- RX DX% 29.9% > TX DX% 20.6%
- 裁决：**「EFHW 瓶颈在接收」在本站点证伪；不要买接收磁环**

写法要求：明确标注这是**本站点**结论，机理仍对（高 QRM 站点确实会 RX 聋），前提不满足而已。不得写成普适结论。

**五刀切断实验**（当天可做完，每刀砍掉一半候选门）：

| 刀 | 做法 | 读数含义 |
| --- | --- | --- |
| 1 | 天线口换 50 Ω 假负载 | 噪声消失 → 门①②；仍在 → 门③④ |
| 2 | 只断天线导线，保留馈线 | 噪声仍在 → 门②（CMC 有靶子）；大幅下降 → 门①（CMC 没用） |
| 3 | 临时夹式磁环 A/B | 噪声立刻变 → 确认共模路径 |
| 4 | 电台改电池供电（拔掉充电器/网线） | 噪声变 → 门③ |
| 5 | 手持机巡场 | 噪声随位置剧烈变化 → 门④，且指向具体电器 |

**两条纪律必须写在表格下方**，否则整章不可信：
1. 只用**相对**比较。S 表读数受 AGC、前置衰减、源阻抗变化影响；换假负载本身就改变了接收机看到的源阻抗。
2. 同一时段、同一频率、同一设置。

出处：ARRL《Radio Frequency Interference (RFI)》给出的官方流程与之一致（`先问从哪儿来，别问是什么`；断路器分路测试是 `best first step`）。

### 3.2 §02 Six sources, four doors

六张档案卡，**固定五段模板**：`机理` / `判据` / `CMC 裁决` / `解药` / `依据`。

固定模板的价值是**可横向比较**——同样叫「环境干扰」，CMC 的裁决为什么不同，一眼可见。

| 卡 | 源 | 主路径 | CMC 裁决 | 关键依据 |
| --- | --- | --- | --- | --- |
| 1 | 电力线间隙放电 | 门① | **否** | ARRL 原文；IEEE Std 1897-2024 |
| 2 | 开关电源 | 门③ | **否**（同轴）；市电线有效 | GB/T 9254.1-2021 限值算术 |
| 3 | 电动汽车充电器 | 门① | **部分** | GB/T 18487.1-2015；**无 HF 专项实测** |
| 4 | 光伏逆变器 | 门①+③ | **部分** | ARRL 明确列为三大类之一 |
| 5 | PLC / BPL | 门① 带内 | **否** | BPL 带宽定义即 2–30 MHz |
| 6 | LED / 生长灯 | 门①+④ | **部分** | ARRL 明确列为三大类之一 |

**卡片 1（电力线）必须包含两条纠正性事实**：

1. ARRL 原文：`corona discharge is rarely, if ever, a source of power-line noise`。真凶是**间隙放电/电弧**（松动/破损金具、间距不足）。中文社区常说的「电晕放电干扰」基本不成立。
2. **中国 50 Hz 电网 → 100 Hz 突发率**。ARRL 原文按 60 Hz 写 120 Hz，本页按中国电网换算并注明。配套判据：示波器双水平带缓慢漂移；**雨天噪声减弱或消失**；**刮风时噪声变化**。后两条不需要仪器。

**卡片 2（开关电源）必须包含限值算术**，这是全页的支点：

GB/T 9254.1-2021（≈CISPR 32）Class B 传导骚扰限值 → 折算到 50 Ω：

| 限值 | 电压 | 折算功率 |
| --- | --- | --- |
| 56 dBμV | 631 μV | **−51.0 dBm** |
| 60 dBμV | 1.00 mV | **−47.0 dBm** |
| 66 dBμV | 2.00 mV | **−41.0 dBm** |

推论（必须写明）：一台**完全合规**的开关电源，其传导发射相当于 −51 dBm；而安静乡村 HF 噪声底常在 −120 dBm 量级。**合规 ≠ 不干扰。限值是商业与频谱之间的折中，不是业余 HF 可用性的保证。**

并给出共模/差模分解：差模由 X 电容抑制，共模由 Y 电容 + 共模扼流圈抑制。劣质电源省成本先省后两件，正好是高频段唯一有效的两件。

**卡片 3（充电桩）的诚实缺口必须写在卡里**：本库检索不到公开的、针对充电桩 HF 频段（1.8–30 MHz）的专项测量，现有公开案例集中在传导发射超标整改与 125 kHz 非 HF 频段。因此该卡**只能写到机理层**（kW 级开关电源 + 数米充电电缆 + PE 导体 = 大共模天线），**不得出现「实测显示充电桩干扰 40 m 波段 XX dB」这类陈述**。

**末尾分源 CMC 裁决表**（本页枢纽，§06 复述）：

| 源 | 主路径 | 同轴 CMC 有效? | 解药在哪 |
| --- | --- | --- | --- |
| 电力线间隙放电 | 门① 再辐射 | **否** | 投诉 + 几何规避 |
| 自家开关电源 | 门③ | **否** | 市电线/直流线 CMC |
| 自家电脑/网线 | 门④ | **否** | 该电缆上加磁环 |
| 邻居 LED / 电源 | 门① 为主 | **部分** | 源侧 + 天线几何 |
| 电动汽车充电器 | 门① 为主 | **部分** | 交涉 + 几何 |
| 光伏逆变器 | 门①+③ | **部分** | 源侧 + 市电侧 |
| PLC / BPL | 门① 带内 | **否** | 频率协调 / 投诉 |
| **馈线屏蔽层拾取的近场噪声** | **门②** | **✅ 完全有效** | **同轴 CMC** |

判定判据只有一条：**CMC 只作用于「装了它的那根导体上的共模路径」。** 由此推出三条：
装在同轴上，对天线导线直接收的噪声无效；对市电传导进来的噪声无效；**对已经完成模式转换的噪声无效**。

### 3.3 §03 Door ②: the shield

七条论证链，按顺序：

1. **接收机只响应同轴线内外导体之间的差分模。** 屏蔽层外表面上的共模电流本身进不了接收机——它必须在不对称点（49:1 变压器不平衡、馈电点、机箱接地）先被**转换**成差分电压。这是全页最重要的一句话。
2. **所以 CMC 不是滤波器，是模式选择器。** 理想 CMC 对差分模近乎零阻抗、对共模模高阻抗。想要的信号走差分模照过，屏蔽层上的噪声被拦。顺带解释它为什么不改善匹配、不提高效率、不改变 SWR。
3. **分压模型**：`A ≈ 20·log₁₀(1 + Z_cm/Z_loop)`。Z_loop 不是 50 Ω，是噪声源那条环路的阻抗。附可复算表（Z_loop = 50 / 200 Ω 两档，Z_cm 从 50 Ω 到 5000 Ω）。**读法：夹式小磁珠 Z_cm 常在几十欧量级 → 只给个位数 dB；要做成事必须 kΩ 级。**
4. **模型局限必须一并写明**：Z_cm 是复数 `R + jX`，电阻性（有损）比电抗性有效；模型忽略「串入 Z_cm 会改变共模电流分布」。实用后果是单个扼流圈常只**搬走谐振点**，典型症状「7 MHz 好了，5 MHz 更糟」。因此要两个扼流圈（馈电点 + 小屋入口），把馈线切成每段 < λ/4。
5. **材料的频率依赖**：Z_cm ∝ N²，磁导率随频率变。**「一个扼流圈覆盖 1.8–30 MHz」是伪命题。** 引本库已有 Fair-Rite μ'/μ'' 一手数据（43 料约 7 MHz 起 μ'' 接近或超过 μ'；这对变压器是坏消息，对扼流圈反而是好事——有损的扼流圈吸收能量、不产生谐振）。
6. **接收端的不对称**（最少被讲的一条）：接收电平 µV 级，**铁氧体永远不会饱和**，发射侧的功率与发热约束在接收上不存在。推论双向：只服务接收的扼流圈可以堆匝数、用高 μ 材料；主路上的必须同时扛发射。**接收上效果最好的扼流圈，可能恰恰是发射上会烧掉的那个。**
7. **地网是前提**：没有回流路时，串入扼流圈只是把它变成天线负载的一部分，共模电流改从机箱和市电找路。**先有地网，再有扼流圈。** 馈电点陷阱：同轴本身充当回流路时，在馈电点扼流等于掐断天线自己的回流路径；此时扼流圈须离馈电点 ≥3 m（ARRL 手册，经 `efhw_cmc.md`）。若有独立地网导线，则馈电点扼流是最佳拓扑。

处方走 `[C]`，不自己编数：Mix 31 覆盖 80–20 m（FT240-31 上 5–9 圈 RG-8X）、Mix 43 覆盖 40–10 m（FT240-43 上 6–10 圈）、夹式磁珠效果较差、空心 PVC 扼流圈 40 m 以上有效但低频段无效。

### 3.4 §04 The other three doors

- **门③ 市电/地环**：传导路径；判据（电池供电 A/B）；处置（市电线/直流线加共模扼流圈、切断地环）；**安全红线：不得断开市电保护地线**，扼流圈通过工频与直流、只挡射频，这才是正确做法。
- **门① 天线几何**：CMC 无效的判别（CMC 前后噪声几乎不动，改朝向/高度噪声明显变化）；处置是抬高、远离房屋、改变走向、加接收专用天线。EFHW 的固有弱点：末端馈电 = 电压波腹 = 电场最大点。
- **门④ 近场**：电台/SDR/网线本身是小天线；巡场法定位；处置是物理距离与该电缆上的磁环。

### 3.5 §05 Prove it worked

- 复述 §01 的两条纪律，不重复解释。
- 仪器：MRRC 的 `interval_smeter_update`（S 表）与 WDSP 频谱——**读者可能已经有**，不需要另买。
- 客观方法：PSKReporter `noise_floor` 端点（本站画像页用的同一套），能在改造前后给出可比较的噪声底读数。指向 `bg1sb-antenna.html` 的方法论。
- 明确写「不许声称的结论」：单次白天 A/B 不能得出「改善 X dB」，因为噪声场随时间变化；只能说不低于某个可分辨的下限。

### 3.6 §06 What a choke cannot fix

- CMC 治不了的清单（复述 §02 的裁决表并收口）。
- TX/RX 分离：有源磁环（MLA-30+ / Wellgood v4 / W6LVP）+ T/R 切换。**必须同时写明这只对高 QRM 站点有意义**，并回指 §01 的 BG1SB 反例。
- 投诉路径：工信部 **12381** 无线电干扰投诉受理热线（2023-03-20 开通）；依据《无线电干扰投诉和查处工作实施细则》(2018)。**关键细节：短波、卫星业务不由地方受理，转发至国家无线电监测中心和部无线电管理局。**
- 安全红线复述。

## 4. 事实与引用纪律（本页最高风险项）

沿用 `baluns.html` 已生效的两级标签，但**本页不产出新的 [M] 数据**：

- `[C]` 有可查来源 → 内联引用原始文献（ARRL、IEEE 1897-2024、GB/T 9254.1、GB/T 18487.1、Fair-Rite 数据表、PA9X、VE3IPS）
- `[算式]` 当场可复算 → 分压模型、dBμV→dBm 折算。必须给出算式本身，让读者能自己算出同样的数
- `—` 未测 → 留破折号并注明来源缺口

**硬性禁止**：
1. **本页 `tag-m`（实测徽章）计数必须为 0。** 我们没测，就不许出现实测徽章。这是门禁的硬检查项。
2. 不得为凑表格生成看似专业的数值（如随手写「扼流圈插损 0.2 dB」）。
3. 充电桩不得出现 HF 频段的实测断言（§3.2 已说明缺口）。
4. BG1SB 反例必须标注为**本站点**结论，不得升格为普适论断。
5. 本页不得自述跨项目可比数字（版本、测试数、发布状态），需要时链 portal 证据账本。
6. 不得声称本产品系列由 AI/Agent 建造。

**实施时必须先核对的一处**：§3.2 的 GB/T 9254.1-2021 Class B 限值表（0.15–0.5 MHz 准峰值 66→56 dBμV；0.5–5 MHz 56 dBμV；5–30 MHz 60 dBμV）来自检索片段，片段对第三段做了简化。实施时须先核对标准正文再定稿表格；`[算式]` 部分的三个折算值（56/60/66 dBμV → −51.0/−47.0/−41.0 dBm）本身可当场复算，不受影响。

## 8. 范围外（YAGNI）

- 不新建 CSS/JS 文件，不引入框架，不做构建步骤

- 不做交互式计算器（分压模型给公式与表格，不上 JS）
- 不做噪声源定位的仪器指南（巡场法只给方法，不写成设备选购）
